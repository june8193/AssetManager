## 3. 서버 DB 수정 가이드 (서버 PC에서 수행)

거래 일자를 변경하는 대신, 거래가 실제로 발생한 8/1자의 스냅샷을 바로잡아 회계적 정합성을 맞춥니다.

### 대상 레코드
* 테이블: `account_snapshots`
* 조건: `account_id = 13` (카카오뱅크) AND `snapshot_date = '2026-08-01'` (또는 `id = 487`)

### 변경 항목
* `total_valuation`: `64464284.0` $\rightarrow$ **`65464284.0`** (+1,000,000원)
* `period_deposit`: `-13524497.0` $\rightarrow$ **`-12524497.0`** (+1,000,000원)
* ⚠️ **주의**: `total_profit` 컬럼(-3,498,542)은 타 계좌들과 함께 일괄 마이그레이션 예정이므로 이번 수정 대상에서 제외합니다.

### 실행 SQL
```sql
-- 8/1 카카오뱅크 스냅샷 잔고 및 입출금 100만원 증액 수정
UPDATE account_snapshots
SET total_valuation = 65464284.0,
    period_deposit = -12524497.0
WHERE id = 487;
```
