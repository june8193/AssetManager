# 자산 배분 비율 계산기 (Asset Allocation Calculator) 디자인 스펙

본 문서는 사용자가 설정한 목표 자산 비중과 현재 자산 현황을 계층적으로 비교하여 리밸런싱에 필요한 매수/매도 금액을 계산해 주는 기능에 대한 상세 설계입니다.

## 1. 개요
- **목적**: 대분류, 중분류, 개별 종목으로 이어지는 계층 구조를 통해 정밀한 자산 배분 전략 수립 및 리밸런싱 지원
- **주요 특징**:
  - **계층형 인터페이스**: 대분류 > 중분류 > 종목 순의 트리 구조 (Collapsible)
  - **인라인 실시간 비교**: 목표 비중 입력 시 현재 비중과 즉시 비교 및 조정액 계산
  - **입력 모드 전환**: 중분류 및 종목의 목표 비중을 '상위 분류 내 비중(%)' 또는 '전체 자산 대비 비중(%)'으로 선택 입력 가능
  - **자동 카테고리 로드**: DB(`assets` 테이블)에 정의된 카테고리를 기반으로 목록 구성

## 2. 사용자 인터페이스 (UI)
- **위치**: 사이드바 '비율계산기' 페이지
- **상단 컨트롤**:
  - **추가 투자금**: KRW 단위 입력 (총 자산 평가액에 합산되어 목표액 계산)
  - **입력 모드 토글**: '대분류 내 % (상대적)' vs '전체 대비 % (절대적)'
  - **저장 버튼**: 설정된 목표 비중을 DB에 영구 저장
- **메인 테이블 (계층형)**:
  - **Level 1 (대분류)**: 주식, 채권, 현금 등 (항상 표시)
  - **Level 2 (중분류)**: 국내주식, 해외주식 등 (대분류 클릭 시 확장)
  - **Level 3 (종목)**: 개별 티커 및 종목명 (중분류 클릭 시 확장)
- **컬럼 구성**:
  - **카테고리/종목명**: 아이콘 및 트리 인디케이터 포함
  - **현재 가치**: 원화(KRW) 환산 평가액
  - **현재 비중**: 설정된 입력 모드에 따른 현재 비중 표시
  - **목표 비중**: 사용자 입력 필드 (%)
  - **조정 필요액**: (목표 가치 - 현재 가치)
  - **액션**: '매수'(+), '매도'(-), '유지' 표시

## 3. 데이터 모델 (Database)
- **기존 `target_ratios` 테이블 활용 및 확장**:
  - `id`: PK
  - `category_name`: 카테고리명 또는 종목 티커
  - `category_type`: 'major', 'sub', 'stock'
  - `target_percentage`: 목표 비중 (%)
  - `parent_category`: 상위 카테고리명 (Sub인 경우 Major명, Stock인 경우 Sub명)
  - `mode`: 'relative' (상위 내 비중) 또는 'absolute' (전체 대비) -> UI 설정값 저장을 위한 컬럼 고려

## 4. 로직 및 API 설계
- **계산 로직**:
  1. `총 목표 자산` = 현재 총 평가액 + 추가 투자금
  2. `대분류 목표액` = 총 목표 자산 * (대분류 목표 % / 100)
  3. `중분류 목표액`:
     - 상대 모드: 대분류 목표액 * (중분류 목표 % / 100)
     - 절대 모드: 총 목표 자산 * (중분류 목표 % / 100)
  4. `종목 목표액`:
     - 상대 모드: 중분류 목표액 * (종목 목표 % / 100)
     - 절대 모드: 총 목표 자산 * (종목 목표 % / 100)
  5. `조정 필요액` = 각 계층별 목표액 - 현재 평가액

- **Backend API**:
  - `GET /api/ratios/hierarchy`: DB의 assets와 target_ratios를 병합하여 계층 구조 데이터 반환
  - `POST /api/ratios/targets`: 사용자가 설정한 계층별 목표 비중 일괄 저장

## 5. 테스트 및 예외 처리
- **합계 검증**: 상위 계층의 목표 비중 합이 100%가 되도록 프론트엔드 유효성 검사
- **미분류 자산**: 카테고리가 지정되지 않은 종목은 '기타' 대분류로 자동 할당
- **환율**: 시스템 내 최신 환율 정보를 실시간 적용

## 6. 향후 확장성
- 자산군별 기대 수익률 입력을 통한 시뮬레이션 기능
- 리밸런싱 주문 연동 (API 지원 시)
