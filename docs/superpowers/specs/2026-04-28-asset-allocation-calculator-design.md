# 자산 비율 계산기 (Asset Allocation Calculator) 디자인 스펙

본 문서는 사용자가 설정한 목표 자산 비중과 현재 자산 현황을 비교하여 리밸런싱에 필요한 매수/매도 금액을 계산해 주는 기능에 대한 상세 설계입니다.

## 1. 개요
- **목적**: 자산 배분 전략에 따른 목표 비중 유지 및 리밸런싱 의사결정 지원
- **주요 기능**:
  - 대분류 및 중분류별 목표 비중 설정 및 DB 저장
  - 현재 자산 현황(평가액) 기반 실시간 비중 계산
  - 추가 투입 금액을 포함한 매수/매도 시뮬레이션
  - 전체 자산 기준 계산

## 2. 사용자 인터페이스 (UI)
- **위치**: 사이드바 메뉴에 '비율계산기' 항목 추가 (독립 페이지)
- **구성**:
  - **설정 영역 (좌측)**:
    - 대분류(주식, 채권, 현금 등) 목표 % 입력 필드 (합계 100% 검증)
    - 대분류별 하위 중분류 목표 % 입력 필드 (해당 대분류 내에서 100% 검증)
    - '목표 비중 저장' 버튼
  - **결과 영역 (우측)**:
    - '추가 투자금' 입력 필드 (KRW)
    - '계산하기' 버튼
    - 시뮬레이션 결과 테이블: 카테고리명, 현재 비중(%), 목표 비중(%), 조정 필요 금액, 권장 액션(매수/매도)

## 3. 데이터 모델 (Database)
- **테이블명**: `target_ratios`
- **컬럼 구성**:
  - `id`: INTEGER (PK)
  - `category_name`: VARCHAR (카테고리 이름, 예: '주식', '미국 주식')
  - `category_type`: VARCHAR ('major' 또는 'sub')
  - `target_percentage`: FLOAT (0.0 ~ 100.0)
  - `parent_category`: VARCHAR (중분류일 경우 소속 대분류명, Nullable)
  - `updated_at`: DATETIME (최종 수정 시각)

## 4. API 설계 (Backend)
- **`GET /api/ratios/targets`**:
  - 저장된 모든 목표 비율 데이터를 반환
- **`POST /api/ratios/targets`**:
  - 목표 비율 리스트를 받아 일괄 업데이트 또는 생성
- **`GET /api/ratios/calculate`**:
  - 파라미터: `additional_cash` (Optional, default=0)
  - 로직:
    1. 현재 모든 활성 계좌의 자산 평가액 합산 (원화 기준)
    2. 총 자산 = 현재 총 평가액 + `additional_cash`
    3. 각 카테고리별 목표 평가액 = 총 자산 * (대분류 % / 100) * (중분류 % / 100)
    4. 조정 금액 = 목표 평가액 - 현재 카테고리별 평가액
    5. 결과 반환 (카테고리별 현재액, 목표액, 차액, 액션)

## 5. 테스트 전략
- **Unit Test**:
  - 비중 계산 로직 검증 (추가 현금 유무에 따른 정확도)
  - 합계 100% 미달/초과 시 유효성 검사 로직
- **API Test**:
  - 목표 비율 저장 및 조회 기능
- **E2E Test**:
  - UI에서 비율 입력 후 계산 결과가 대시보드 데이터와 일치하는지 확인

## 6. 제약 및 고려 사항
- 자산 데이터에 대분류/중분류가 설정되지 않은 '미분류' 자산에 대한 처리 필요
- 환율은 시스템 내 최신 환율 데이터를 사용
- 종목별 매수 수량 제안은 소수점 발생 시 내림 처리 (현실적인 매수 가능 수량)
