# 종목별 투자 가설 저장소 (Investment Theses)

이 디렉터리는 포트폴리오에 편입된 개별 종목들의 **독립적인 펀더멘털 투자 가설(Thesis)**을 체계적으로 기록하고 관리하는 단일 진실 공급원(SSOT)입니다.

---

## 1. 투자 가설 관리 원칙

1. **독립적 팩트 기반**: 매크로 전망, 전문가 의견, 뉴스, 차트 패턴 소음이 아닌 **본인만의 직접적 제품/서비스 경험 및 확인 가능한 실적 지표**에 기반합니다.
2. **사전 정의된 Exit 트리거**: 주가 하락이 매도 사유가 되지 않으며, **가설이 훼손되는 명확한 펀더멘털 조건**을 사전에 정의합니다.
3. **자산 점검(Audit)과의 유기적 연계**:
   - `asset-auditor` 스킬 실행 시 이 디렉터리의 가설 파일들을 자동으로 로드하여 검증합니다.
   - 점검 과정에서 도출된 포지션 조정 및 미래 실행 계획(Action Plan)은 해당 종목 파일에 지속적으로 누적 갱신됩니다.

---
