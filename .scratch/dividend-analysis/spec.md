# [Spec] AssetManager 배당 분석 (Dividend Analysis) 기능 스펙 명세서

## Problem Statement

자산 관리 시스템(AssetManager) 이용자는 주식 및 배당주 자산을 보유하고 있으나, 지금까지 각 종목별 수령 배당금, 월별/연도별 누적 배당금 추이, 그리고 현재 평가액 대비 실질 배당 수익률을 한눈에 파악하기 어려웠습니다.  
또한 주가가 변동하거나 특정 목표 매수가를 가상으로 설정했을 때 예상되는 시가 배당률(Yield)을 실시간으로 시뮬레이션해볼 수 있는 기능이 부재하여 투자 의사결정에 불편함이 존재했습니다.

## Solution

AssetManager에 독립적인 **[배당 분석] (`/dividend`)** 메뉴 대시보드를 구축합니다.  
이 대시보드는 DB의 거래 원장(`transactions` 중 `INTEREST` 이자/배당 항목) 데이터를 바탕으로 총 누적 수령 배당금 및 월별/연도별 수령 추이를 막대-꺾은선 콤보 차트로 시각화합니다.  
또한, 각 종목별 연간 추정 배당금 및 현재 시가 배당률을 표로 제공함과 동시에, 사용자가 종목별 **가상 주가를 인라인으로 직접 수정**하면 즉시 가상 배당률(%)이 실시간 산출되는 시뮬레이션 환경(Variant A 시안 구조)을 제공합니다.

## User Stories

1. **As an** 자산 관리자, **I want to** 배당 분석 메뉴(`/dividend`)에 접근할 수 있어서, 내 포트폴리오의 배당 관련 핵심 지표를 한눈에 확인할 수 있기를 원한다.
2. **As an** 투자자, **I want to** 전체 총 누적 배당금과 올해(YTD) 수령 배당금 및 평균 연간 배당률 요약 카드를 조회하여, 배당 현금흐름의 규모를 파악할 수 있기를 원한다.
3. **As an** 투자자, **I want to** 월별 배당 수령액(막대)과 누적 배당금(꺾은선)이 합성된 콤보 그래프를 조회하여, 배당금 재투자 및 성장 추이를 직관적으로 시각화하여 보기를 원한다.
4. **As an** 주식 보유자, **I want to** 각 종목별 올해 수령액, 연간 추정 배당금, 현재 시가 배당률(%)을 조회하여, 어떤 종목이 가장 높고 효율적인 배당 수익을 내고 있는지 평가할 수 있기를 원한다.
5. **As an** 투자자, **I want to** 한국 주식의 배당률은 원화(KRW) 기준으로, 미국 주식의 배당률은 달러(USD) 기준으로 각각 고유 통화 기준 배당률을 조회하여, 환율 변동 왜곡 없이 정확한 수익률을 계산할 수 있기를 원한다.
6. **As an** 배당주 매수 계획 수립자, **I want to** 상세 표에서 특정 종목의 가상 주가를 직접 인풋 박스에 수정 입력할 수 있어서, 주가가 하락하거나 목표 매수가에 도달했을 때의 예상 배당률(%)을 즉시 시뮬레이션할 수 있기를 원한다.
7. **As an** 개인 투자자, **I want to** 올해 배당 수령 이력이 없는 신규 보유 종목의 경우 배당금이 0원, 배당률이 `-`로 표기되는 것을 확인하여, 불확실한 수치가 오인되지 않도록 구분되기를 원한다.
8. **As an** 투자자, **I want to** 1월 연초 시점에도 당월 수령액을 기반으로 12개월 연환산 추정 배당금이 일관되게 산출되는 것을 확인하여, 일관성 있는 배당 통계를 얻기를 원한다.

## Implementation Decisions

### 1. 배당 산정 및 연환산 공식
- **추정 연간 배당금 산식**:
  $$\text{추정 연간 배당금} = \left( \frac{\text{올해(1월~현재월) 수령 배당금 총액}}{\text{현재 월(1~12)}} \right) \times 12$$
- **상황 1 (올해 수령 이력 0원)**: 추정 연간 배당금 = 0원, 배당률 = `-` 표기
- **상황 2 (1월 연초)**: `(1월 수령액 / 1) * 12` 산식 적용
- **통화별 배당률 산식**:
  - 한국 주식 (KRW): $\frac{\text{원화 연간 배당금}}{\text{원화 주가}} \times 100\%$
  - 미국 주식 (USD): $\frac{\text{달러 연간 배당금}}{\text{달러 주가}} \times 100\%$
  - 대시보드 요약 카드 및 콤보 차트: 현재 환율을 반영하여 **원화(KRW)** 기준으로 통합 집계

### 2. 백엔드 서비스 & REST API 인터페이스
- **서비스 모듈 (`DividendService`)**:
  - DB `transactions` 테이블 (`type == "INTEREST"` 및 메모/유형 검증) 조회
  - `assets`, `accounts` 및 `exchange_rates` 정보 결합
  - 월별/연도별 시계열 집계 및 종목별 연환산 배당금/배당률 데이터 계산
- **REST API 엔드포인트**:
  - `GET /api/dividend/summary`: 요약 카드 지표 (총 누적액, 올해 수령액, 평균 배당률) 및 월별/누적 시계열 차트 데이터 반환
  - `GET /api/dividend/stocks`: 종목별 평가 정보, 수령 실적, 추정 연배당금, 시가 배당률 및 기본 주가 반환

### 3. 프론트엔드 대시보드 컴포넌트 & UX 구조 (Variant A 기반)
- **독립 라우트**: `/dividend` (사이드바 `비중 점검` 하단에 `배당 분석` 메뉴 독립 추가)
- **UI 레이아웃 구조**:
  - **상단**: 4개 요약 카드 (총 누적 배당금, 올해 배당금, 평균 배당률, 월평균 수령액)
  - **중단**: Recharts 기반 `ComposedChart` (막대: 당월 배당금, 꺾은선: 누적 배당금)
  - **하단**: 상세 그리드 표 (`종목명`, `통화`, `현재가/평단가`, `올해 수령액`, `추정 연배당금`, `시가 배당률`, `가상 주가 입력`, `가상 배당률`, `총 누적 배당금`)
  - **인라인 가상 주가 입력**: 각 종목 행의 가상 주가 인풋 수정 시, 로컬 컴포넌트 상태 반응형으로 `가상 배당률(%)` 즉시 재계산

## Testing Decisions

### 1. 백엔드 비즈니스 로직 테스트 (단위 테스트 Seam)
- **Seam**: `DividendService` 모듈
- **테스트 케이스**:
  - 배당 거래내역이 있는 종목의 YTD 연환산 공식 검증 (`(YTD 수령액 / 현재월) * 12`)
  - 배당 이력이 0인 신규 종목의 예외 처리 (0원 및 `-` 표기 반환 확인)
  - KRW 및 USD 자산의 통화별 배당률 산출 정확도 검증

### 2. 백엔드 API 통합 테스트 (REST API Seam)
- **Seam**: `GET /api/dividend/summary` 및 `GET /api/dividend/stocks` FastAPI 라우터
- **테스트 케이스**:
  - 데이터베이스에 주식 및 배당 거래 내역이 존재할 때 API 응답 데이터 스키마 및 계산 결과 검증

### 3. 프론트엔드 컴포넌트 & E2E 테스트 (UI Seam)
- **Seam**: `DividendAnalysisPage` 컴포넌트 및 Playwright E2E 브라우저
- **테스트 케이스**:
  - `/dividend` 페이지 정상 렌더링 및 Recharts 차트 렌더링 검증
  - 종목별 가상 주가 입력 필드 값을 변경했을 때 `가상 배당률(%)` 텍스트가 즉시 변경되는지 인터랙션 검증

## Out of Scope

- 키움 REST API 이외의 제3자 외부 증권사 API 자동 연동 (기존 키움 수집기 및 수동 입력 거래내역에 의존)
- 미래 기업 공시 배당금(DPS)의 외부 웹 크롤링 자동 반영 기능 (실제 수령 실적 기반 연환산 산식 우선 적용)
