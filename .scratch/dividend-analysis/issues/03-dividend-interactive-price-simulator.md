# 03 — 종목별 가상 주가 인라인 수정 & 실시간 가상 배당률 시뮬레이터 구현

**What to build:** 배당 분석 대시보드 하단 상세 표에서 각 종목 행의 가상 주가 인풋 박스(Inline Input)에 목표 주가나 가상 매수가를 수정 입력할 때, 해당 종목의 `가상 배당률(%)`이 실시간 반응형으로 즉시 계산되어 변화하는 인터랙티브 시뮬레이션 기능과 E2E 검증을 완성합니다.

**Blocked by:** 02 — 배당 분석 메인 대시보드 UI (요약 카드, 콤보 차트, 상세 표) 구현

**Status:** resolved

- [x] 상세 표 내 각 종목 행에 가상 주가 수정용 Inline Input 박스 배치
- [x] 입력값 수정 시 `((추정 연간 배당금 / 가상 주가) * 100)` 공식을 통한 `가상 배당률(%)` 실시간 재계산
- [x] 가상 주가 변경에 따른 반응형 UI 상태 관리 및 예외 입력(0 이하) 방어 처리
- [x] `uv run scripts/dev.py` 구동 후 Playwright 기반 E2E 검증 및 최종 스크린샷 캡처
