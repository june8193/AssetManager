# 02 — [프론트엔드] PerformanceTable 월별 모드 지원 및 대시보드 탭 UI 통합

**What to build:** 
성과 테이블 컴포넌트(`PerformanceTable`)에 `monthly` 모드를 추가하고 페이지네이션을 연동하며, 대시보드 페이지의 테이블 영역을 **[연도별 | 월별 | 일별] 탭(세그먼트 컨트롤)**으로 통합하여 대시보드에서 월간 자산 현황과 수익률을 조회할 수 있도록 합니다.

**Blocked by:** 01 — [백엔드] 월간 자산 통계 계산 엔진, 대시보드 API 및 MCP 도구 구현

**Status:** ready-for-agent

- [ ] `PerformanceTable`에 `period="monthly"` prop이 추가되어 연월, 기말자산, 전월비 증감, 순입금, 투자손익, 수익률 컬럼을 정확한 통화/퍼센트 포맷 및 마스킹과 함께 렌더링한다.
- [ ] 월별 모드 테이블에서 10/20/50개 단위의 페이지네이션 컨트롤이 정상 동작한다.
- [ ] 대시보드 페이지에서 월간 통계 API 데이터를 조회하고, 상단 탭(연도별/월별/일별) 클릭 시 선택된 기간의 테이블로 깔끔하게 전환된다.
- [ ] Vitest 및 React Testing Library 컴포넌트 단위 테스트를 통해 탭 전환 및 월별 테이블 렌더링 동작을 검증한다.
