# 03 — [통합] 벤치마크 4대 지수 월별 비교 백엔드 및 벤치마크 탭 UI 연동

**What to build:** 
4대 시장 지수(KOSPI, KOSDAQ, S&P 500, NASDAQ)의 월별 수익률을 산출하여 포트폴리오 월간 ROI와 비교하는 백엔드 서비스/API를 구현하고, 벤치마크 페이지의 테이블 영역을 **[연도별 | 월별 | 일별] 탭**으로 통합하여 월간 지수 비교 성과를 조회할 수 있도록 합니다.

**Blocked by:** 
- 01 — [백엔드] 월간 자산 통계 계산 엔진, 대시보드 API 및 MCP 도구 구현
- 02 — [프론트엔드] PerformanceTable 월별 모드 지원 및 대시보드 탭 UI 통합

**Status:** ready-for-agent

- [ ] 벤치마크 서비스에서 4대 시장 지수의 월별 시작 거래일 종가와 마지막 거래일 종가를 기반으로 월별 지수 수익률을 산출한다.
- [ ] 벤치마크 비교 API 응답에 `monthly` 비교 배열이 추가되어 반환된다.
- [ ] `PerformanceTable`의 지수 비교 모드(`type="comparison"`, `period="monthly"`)가 정상적으로 월별 지수 및 포트폴리오 ROI를 렌더링한다.
- [ ] 벤치마크 페이지에서 **[연도별 | 월별 | 일별] 탭**을 통해 월간 지수 비교 테이블을 직관적으로 탐색할 수 있다.
- [ ] 백엔드 pytest 및 프론트엔드 vitest 테스트로 계산 정합성 및 UI 렌더링을 검증한다.
