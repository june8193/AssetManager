# 03 — 모바일 전용 지출 관리 화면(MobileExpensesPage) 및 기간 직접 지정 패널 구현

**What to build:** 
모바일 사용자가 스마트폰 뷰포트에 최적화된 인터페이스로 기간별 지출 현황을 파악할 수 있도록, 모바일 전용 지출 관리 화면을 구축합니다. 가로 스크롤 프리셋 칩과 토글형 기간 직접 지정(`시작월 ~ 종료월`) 패널, 총 지출 및 월평균 지출 요약 카드, 카테고리 비중 랭킹, 카드형 거래 내역 및 100건 단위 페이징(더보기) 기능을 제공합니다.

**Blocked by:** 01 — 다기간 지출 통계 API 확장 및 데스크탑 기간 분석 연동, 02 — 모바일 6대 탭 바 확장 및 지출 라우트(/m/expenses) 기반 구축

**Status:** resolved

- [x] 모바일 요약 카드 구현: 기간 총 지출, 월평균 지출(신규 지표), 직전 동기간 대비 증감률 렌더링
