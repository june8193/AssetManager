# 05 — E2E 통합 시나리오 검증 및 최종 정리

**What to build:**
개발 서버(`scripts/dev.py`) 환경에서 명세서 업로드부터 수동 분류 및 통계 제외 체크, 미분류 차단 확인, 저장 확정, 대시보드 및 원장 반영에 이르는 전체 사용자 흐름이 정상 작동함을 브라우저로 최종 검증하고 스크린샷을 기록합니다.

**Blocked by:** 04 — 거래 원장 및 대시보드 UI 단순화

**Status:** resolved
 
- [x] 개발 서버(`uv run scripts/dev.py`)를 백그라운드로 구동하고 내장 브라우저(`http://localhost:5173`)로 지출 관리 페이지에 접속한다.
- [x] 카테고리 관리 모달에서 탭 없이 단일 목록으로 '구독료', '모임회비'가 노출되는지 확인한다.
- [x] 명세서 업로드 모달에서 파일 업로드 후 미리보기에서 모든 거래의 카테고리가 '미분류'로 표시되는지 검증한다.
- [x] '통계 제외'를 체크한 거래의 카테고리 드롭다운이 비활성화(`disabled`)되는지 검증한다.
- [x] 미분류 거래가 남아있는 상태에서 '확정 및 저장' 버튼이 비활성화되고 경고 문구가 노출되는지 검증한다.
- [x] 모든 거래에 카테고리를 지정(또는 통계 제외 체크)한 후 정상 저장되고 대시보드 및 원장에 반영되는지 검증한다.
- [x] 원장 테이블에서 2차 카테고리 열 없이 표시되고 단일 카테고리 필터링이 정상 작동하는지 검증한다.
- [x] 주요 검증 화면 스크린샷을 저장하고 개발 서버 프로세스를 정상 종료(kill)한다.
