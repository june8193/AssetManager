# 04 — 거래 원장 및 대시보드 UI 단순화

**What to build:**
메인 지출 대시보드에서 2차 카테고리 요약 배너, 2차 카테고리 필터 드롭다운, 원장 테이블의 2차 카테고리 태그 뱃지 및 열을 모두 제거하여 화면을 직관적으로 정돈합니다. 원장 테이블에서도 '통계 제외' 거래는 카테고리 수정 셀렉트가 `disabled` 처리되며, 도넛 차트 및 카테고리 목록에서 '구독료', '모임회비' 등 통합 카테고리가 정상 집계되도록 합니다.

**Blocked by:** 03 — 미분류 거래 커밋 방지 및 원장 저장 유효성 검증

**Status:** resolved

- [x] `Expense` 모델 및 스키마에서 `sub_category_id` 및 관련 필드가 완전히 정리된다.
- [x] 대시보드 통계 API(`GET /api/expenses/stats`) 및 응답 스키마에서 `sub_category_breakdown`이 제거된다.
- [x] 메인 대시보드 상단 KPI 영역 하단의 '지출 특성 요약(구독료 등)' 배너가 제거된다.
- [x] 대시보드 필터 툴바에서 '2차 카테고리' 필터 드롭다운이 제거되고, 단일 카테고리 필터만 유지된다.
- [x] 거래 내역 원장 테이블에서 2차 카테고리 열(태그 뱃지 및 인라인 셀렉트)이 제거되고, 단일 카테고리 선택만 남는다.

- [x] 카테고리 도넛 차트 및 범례에서 '구독료', '모임회비'를 포함한 단일 카테고리별 지출 금액 및 비중이 정상 표시된다.
- [x] 관련 백엔드 대시보드 통계 테스트 및 지출 페이지 컴포넌트 테스트가 통과한다.
