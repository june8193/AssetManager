# 03 — 텔레그램 /restart 커맨드 및 재시작 완료 알림 복원 슬라이스

**What to build:**
텔레그램 봇을 통해 원격에서 데몬 서버를 재시작할 수 있는 `/restart` CLI 명령어와, 서버 재기동 시 완료 알림 메시지를 전송하는 라이프사이클 훅을 구축합니다.

**Blocked by:** 02 — 구글 드라이브 스토리지 경로 일원화 및 과거 감사 기록 연결 슬라이스

**Status:** ready-for-agent

- [ ] `/restart` 명령어 수신 시 대상 스토리지 디렉토리에 `.restart_pending` 플래그 파일이 생성되고 사용자에게 재시작 안내 메시지가 전송된다.
- [ ] 메시지 전송 후 메인 프로세스가 정상 종료(`exit 0`)하여 PM2 데몬에 의한 자동 재시작이 유도된다 (단, 테스트 환경에서는 프로세스 종료가 격리/Mocking된다).
- [ ] `/help` 명령어 도움말 안내 목록에 `/restart`가 추가되고 `set_my_commands` 목록에도 등록된다.
- [ ] 봇 폴링 기동 루틴(`start_polling`)에서 `.restart_pending` 플래그를 검사하여 플래그가 존재하면 등록된 허가 사용자들에게 재시작 완료 알림을 발송하고 플래그 파일을 삭제한다.
- [ ] `/restart` 명령어 디스패치 및 재시작 플래그 검사/알림 로직에 대한 TDD 단위 테스트가 100% 통과한다.
