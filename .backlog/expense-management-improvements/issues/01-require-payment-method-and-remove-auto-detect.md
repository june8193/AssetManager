# 01 — 결제수단 선택 필수화 및 자동 감지 삭제

**What to build:**
명세서 업로드 시 결제수단 '자동 감지' 기능을 완전히 제거하고, 사용자가 등록된 결제수단을 직접 선택해야만 업로드 및 미리보기 파싱이 가능하도록 변경합니다. 결제수단이 선택되지 않은 상태에서는 파싱 버튼이 비활성화되며, 백엔드 API에서도 결제수단 ID가 필수로 검증됩니다.

**Blocked by:** None — can start immediately

**Status:** done

- [x] 명세서 업로드 모달의 결제수단 선택 드롭다운에서 '자동 감지 (권장)' 옵션이 삭제되고, 기본 선택 안내 문구(예: '결제수단을 선택해주세요')가 표시된다.
- [x] 사용자가 결제수단을 선택하기 전까지 '미리보기 파싱' 버튼이 비활성화(disabled)되며 파싱 요청이 전송되지 않는다.
- [x] 결제수단을 선택하고 파일을 업로드하면 정상적으로 미리보기 파싱이 수행된다.
- [x] 백엔드 업로드 미리보기 엔드포인트(`POST /api/expenses/upload-preview`)에서 `payment_method_id`가 필수 파라미터로 검증되며, 누락 시 적절한 4xx 에러를 반환한다.
- [x] 백엔드의 불필요해진 금융기관/계좌 추론 기반 결제수단 자동 매칭 로직이 정리된다.
- [x] 관련 백엔드 API 테스트 및 프론트엔드 모달 컴포넌트 테스트가 통과한다.
