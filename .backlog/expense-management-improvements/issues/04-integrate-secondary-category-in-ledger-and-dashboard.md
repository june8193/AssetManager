# 04 — 지출 원장 및 업로드 미리보기에 2차 카테고리 연동 및 대시보드 반영

**What to build:**
명세서 업로드 미리보기 시 거래별로 2차 카테고리를 선택할 수 있게 하고, 지출 확정 시 원장에 저장합니다. 대시보드 거래 원장 테이블에서 2차 카테고리 뱃지를 확인하고 인라인으로 수정할 수 있으며, 2차 특성별 필터링 및 요약 집계를 제공합니다.

**Blocked by:** 01 — 결제수단 선택 필수화 및 자동 감지 삭제, 03 — 2차 카테고리(지출 특성/태그) 마스터 관리 체계 구축

**Status:** resolved

- [x] `Expense` 모델 및 스키마에 `sub_category_id` (외래키, Nullable) 필드가 추가된다.
- [x] 업로드 미리보기 모달(`ExpenseUploadModal`) 거래 테이블에 '2차 카테고리(선택)' 선택 드롭다운이 추가되고, 커밋 시 `sub_category_id`가 백엔드로 정상 전달되어 저장된다.
- [x] 메인 대시보드(`ExpensesPage`) 거래 원장 테이블에 2차 카테고리 태그 뱃지가 1차 카테고리 옆에 표시된다.
- [x] 거래 원장 테이블에서 2차 카테고리를 인라인으로 즉시 수정/변경할 수 있다.
- [x] 대시보드 상단 필터 영역에 2차 카테고리 필터(예: '전체', '구독료만', '모임회비만')가 추가되어 거래 목록 및 통계를 필터링할 수 있다.
- [x] 대시보드 통계 API 및 카드에 주요 특성(구독료 등) 월간 지출 합계 요약이 제공된다.
- [x] 관련 백엔드 API 테스트 및 지출 페이지 컴포넌트 테스트가 통과한다.
