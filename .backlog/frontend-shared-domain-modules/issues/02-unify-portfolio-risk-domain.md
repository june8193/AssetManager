# 02 — 내재 변동성 리스크 진단 공유 도메인 모듈 구축

**Spec:** [spec.md](../spec.md)

**What to build:** 데스크톱 리스크 분석 페이지와 모바일 리스크 섹션·차트 카드 4개 파일에 중복 복제된 변동성 배수 상태 배지, 게이지 스케일, 액셀 Top 3, 완충 자산 필터, 현금 상단 고정 정렬 및 차트 시계열 변환을 단일 리스크 도메인 모듈로 통합한다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## Acceptance Criteria

- [ ] 변동성 상태 배지, 게이지 스케일, 액셀/완충 자산 분류, 차트 데이터 변환이 단일 도메인 모듈에 응집된다.
- [ ] 데스크톱(시뮬레이션 포함)과 모바일(읽기 전용)이 동일한 리스크 도메인 인터페이스를 공유하고 모바일 새로고침이 실제 완료를 대기한다.
- [ ] 프론트엔드 테스트(Vitest)가 모두 통과한다.
