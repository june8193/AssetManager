# 04 — 데스크탑 지출관리 화면 일괄 삭제 UI 및 사용자 경험 제공

**What to build:**
데스크탑 지출관리 화면(`ExpensesPage.jsx`)의 거래 테이블에 개별 다중 선택 체크박스와 헤더 전체 선택 체크박스를 추가하고, 선택 시 상단에 플로팅 액션바(`{N}개 선택됨`, `선택 삭제`)를 노출하여 여러 건을 일괄 삭제할 수 있게 합니다. 또한 상단 필터 영역에 `현재 조건 전체 삭제` 버튼을 두어 9월 카카오뱅크 등 원치 않는 내역을 확인 대화상자 후 즉시 한 번에 일괄 정리할 수 있도록 합니다.

**Blocked by:** 03 — 지출 거래 내역 일괄 삭제 API 구축 (선택 ID 및 조건별 전체 삭제)

**Status:** resolved

- [x] `expenseService.js`에 `bulkDeleteExpenses(ids)` 및 `clearExpenses(params)` API 연동 함수가 구현된다.
- [x] 테이블 헤더에 전체 선택/해제 체크박스가 추가되고, 각 행 첫 번째 열에 개별 선택 체크박스가 제공된다 (기존 '통계 제외' 체크박스와 완전히 분리).
- [x] 거래 항목이 1개 이상 선택되면 화면에 `{N}개 선택됨` 안내와 `선택 항목 일괄 삭제` 액션 버튼이 나타난다.
- [x] 상단 필터/작업 영역에 `현재 조건 전체 삭제` 버튼이 제공되며, 클릭 시 사용자 확인(`confirm`) 팝업 후 해당 조건(예: 2026-09월 카카오뱅크)의 거래가 일괄 삭제된다.
- [x] 삭제 완료 후 테이블 목록이 즉시 갱신되고, 대시보드 지출 통계(`stats`) 및 차트가 자동으로 다시 집계되어 반영된다.
- [x] 프론트엔드 컴포넌트 단위 테스트(`ExpensesPage.test.jsx`) 및 E2E 브라우저 동작 검증이 통과한다.
