# 02 — 모바일 대시보드 탭 (자산/비중/성과 카드)

**What to build:**
모바일 기기의 작은 화면과 터치 인터랙션에 최적화된 `MobileDashboardPage`를 구현합니다. 기존 `useDashboard` 훅 및 `MaskingContext`의 데이터를 재사용하여 총 자산 요약 카드, 카테고리별 자산 비중 요약 카드, 연간 및 누적 수익률 성과 요약 카드를 터치 친화적 모바일 카드 UI로 렌더링하고, 상단 헤더의 마스킹 토글에 맞춰 금액 모자이크 처리를 실시간 연동합니다.

**Blocked by:** 01 — PWA 인프라 및 적응형 모바일 레이아웃 쉘

**Status:** resolved

- [x] `MobileDashboardPage` 컴포넌트가 구현되고 모바일 대시보드 탭(`/` 또는 `/m/dashboard`)에 연결되어야 함
- [x] 총 자산, 투자 원금, 평가 손익 및 총 수익률이 포함된 총 자산 카드가 모바일 스타일에 맞게 렌더링되어야 함
- [x] 카테고리별(국내주식, 해외주식, 현금, 연금 등) 자산 비중 요약 카드가 렌더링되어야 함
- [x] 연간 수익률 및 누적 성과 요약 카드가 모바일 카드 형태로 명확히 표시되어야 함
- [x] 상단 헤더의 마스킹 버튼 클릭 시 자산 금액이 모자이크/마스킹되어 표시되어야 함
- [x] `MobileDashboardPage` 및 관련 모바일 카드 컴포넌트에 대한 단위 테스트가 작성되고 통과해야 함
