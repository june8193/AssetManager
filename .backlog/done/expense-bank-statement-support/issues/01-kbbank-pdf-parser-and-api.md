# 01 — 국민은행 암호화 PDF 명세서 파싱 및 업로드 프리뷰 파이프라인

**What to build:** 생년월일 6자리(950913 등)로 암호화된 국민은행 입출금 거래내역 PDF 파일을 복호화하여 출금 및 입금 거래를 모두 표준 지출 데이터로 정규화하고, 지정된 대상 연월(`target_year_month`)에 맞는 거래만 필터링하여 업로드 미리보기 응답으로 제공하는 엔드포인트 파이프라인을 구축합니다.

**Blocked by:** None — can start immediately

**Status:** closed

- [x] `pyproject.toml`에 `pypdf>=5.0.0` 의존성이 추가되고 환경에 정상 설치된다.
- [x] 파일 확장자 및 매직바이트, PDF 내용('KB국민은행', 'KB마이핏' 등)을 기반으로 국민은행 포맷이 자동 감지된다.
- [x] 올바른 비밀번호를 제공하면 암호화된 국민은행 PDF가 메모리 상에서 복호화되고 계좌번호, 예금주, 기준년월, 거래 목록이 정규화되어 반환된다.
- [x] 잘못된 비밀번호를 전달하면 `InvalidPasswordError`가 발생한다.
- [x] 거래내역 테이블의 각 행에서 일시(`YYYY-MM-DD HH:MM:SS`), 금액(`amount`), 가맹점(`보낸분/받는분`), 메모(`적요` 및 송금메모), 원본구분(`출금` 또는 `입금`)이 정확히 추출된다.
- [x] `target_year_month`가 주어지면 해당 연월에 속하는 거래만 추출되며, 대상 월 이외의 거래 건수는 `other_month_count`로 집계된다.
- [x] `POST /api/expenses/upload-preview` 엔드포인트에서 국민은행 PDF 업로드 및 비밀번호, 대상 연월 파라미터를 수신하여 미리보기 데이터를 반환한다.
- [x] 국민은행 PDF 파서 및 API 엔드포인트 단위/통합 테스트가 통과한다.
