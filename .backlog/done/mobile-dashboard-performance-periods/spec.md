# Spec: 모바일 대시보드 성과 요약 카드 기간별(연간/월간/일간) 성과 지원

Status: resolved

## Problem Statement

현재 모바일 웹 대시보드의 성과 요약 카드에서는 연도별(Yearly) 투자 성과 데이터만 조회할 수 있습니다. 데스크탑 웹 대시보드에서는 연도별뿐만 아니라 월별(Monthly), 일별(Daily) 성과 데이터까지 상세하게 확인하고 추이를 분석할 수 있으나, 모바일 사용자는 이동 중이나 스마트폰 환경에서 최근 월간 및 일간의 구체적인 투자 수익과 자산 변동 내역을 즉시 파악하기 어렵습니다.

## Solution

모바일 성과 요약 카드(`MobilePerformanceSummaryCard`) 상단에 모바일 친화적인 세그먼트 컨트롤 탭(`[연도별 | 월별 | 일별]`)을 추가하여 사용자가 원하는 기간 단위의 성과 데이터를 손쉽게 조회할 수 있도록 개선합니다.
또한, 데이터 항목이 많은 월별 및 일별 뷰에서는 모바일 화면의 가독성을 저해하지 않도록 5개 단위의 간결한 페이지네이션(`[< 이전] 1 / N [다음 >]`)을 지원하고, 기존 연간 카드와 통일된 카드형 디자인 및 마스킹 보안 기능을 그대로 제공합니다.

## User Stories

1. As a 모바일 투자자, I want to 대시보드 성과 요약 카드에서 [연도별], [월별], [일별] 탭을 눌러 원하는 기간 단위로 전환할 수 있기를 원합니다, so that 언제 어디서든 기간별 포트폴리오 성과를 유연하게 비교 및 조회할 수 있습니다.
2. As a 모바일 투자자, I want to 성과 요약 카드에 처음 진입했을 때 기본적으로 '연도별' 탭이 선택되어 있기를 원합니다, so that 장기적인 연간 누적 성과 흐름을 먼저 한눈에 조망할 수 있습니다.
3. As a 모바일 투자자, I want to '월별' 탭을 선택했을 때 연월(`YY.MM`), 해당 월 자산평가액, 추가 납입액, 월간 수익률, 월간 수익금을 확인할 수 있기를 원합니다, so that 최근 매월의 자산 증감 및 투자 수익 추이를 쉽게 추적할 수 있습니다.
4. As a 모바일 투자자, I want to '일별' 탭을 선택했을 때 스냅샷 기준 일자(`MM.DD`), 해당일 자산평가액, 추가 납입액, 일간 수익률, 일간 수익금을 확인할 수 있기를 원합니다, so that 일자별 포트폴리오의 일간 변동 내역을 면밀히 검토할 수 있습니다.
5. As a 모바일 투자자, I want to 월별 및 일별 탭에서 데이터가 많을 경우 한 번에 5개씩 나누어 표시되고 이전/다음 페이지 이동 버튼을 사용할 수 있기를 원합니다, so that 긴 스크롤 없이 깔끔하고 쾌적한 화면에서 과거 기록을 탐색할 수 있습니다.
6. As a 모바일 투자자, I want to 탭을 전환할 때마다 페이지 번호가 자동으로 첫 페이지(1페이지)로 리셋되기를 원합니다, so that 다른 기간으로 전환했을 때 가장 최신의 성과 데이터를 즉시 확인할 수 있습니다.
7. As a 모바일 투자자, I want to 특정 기간에 데이터가 없는 경우 직관적인 빈 상태 안내 문구("해당 기간 성과 데이터가 없습니다.")를 확인할 수 있기를 원합니다, so that 데이터 누락인지 정상적인 빈 상태인지 혼동하지 않을 수 있습니다.
8. As a 개인정보 보호에 민감한 사용자, I want to 마스킹 모드를 켰을 때 월별 및 일별 성과 리스트의 자산평가액, 추가액, 수익금액이 모두 마스킹(`***`) 처리되기를 원합니다, so that 대중교통이나 공공장소에서도 안심하고 모바일 대시보드를 열람할 수 있습니다.
9. As a 모바일 투자자, I want to 카드 상단에서 전체 포트폴리오의 총 누적 ROI(수익률)를 항상 고정으로 확인할 수 있기를 원합니다, so that 연도별/월별/일별 탭을 탐색하는 중에도 전체 투자 성과의 기준점을 잃지 않을 수 있습니다.

## Implementation Decisions

- **세그먼트 탭 컨트롤 UI**:
  - 카드 상단에 모바일 터치 친화적인 세그먼트 컨트롤 형태의 버튼 그룹(`연도별`, `월별`, `일별`)을 배치합니다.
  - 활성화된 탭은 명확한 배경색과 볼드 폰트로 강조하고, 비활성 탭은 은은한 대비를 제공합니다.
- **기간별 데이터 바인딩 및 정렬**:
  - 기존 대시보드 훅에서 제공하는 `data.yearly`, `data.monthly`, `data.daily` 배열 데이터를 활성 탭에 맞춰 바인딩합니다.
  - 데이터는 최신 날짜가 상단에 오도록 유지합니다.
- **날짜 배지 포맷 최적화**:
  - 연도별: `YYYY` (예: `2026`)
  - 월별: `YY.MM` (예: `26.05`)
  - 일별: `MM.DD` (예: `05.15`)
- **모바일 페이지네이션 로직**:
  - 기본 페이지 크기는 5개(`pageSize = 5`)로 고정합니다.
  - 연도별 데이터는 데이터 수가 적으므로 전체 표시하며, 월별 및 일별 데이터 중 총 항목이 5개를 초과할 때만 하단 페이지네이션 네비게이션(`[< 이전] currentPage / totalPages [다음 >]`)을 렌더링합니다.
  - 탭 변경 시 `currentPage`를 1로 리셋합니다.
- **마스킹 및 포맷팅 컨텍스트 연동**:
  - 프로젝트 공통 마스킹 훅(`useMasking`)을 사용하여 자산액, 추가액, 수익금 수치에 일관된 마스킹 규칙을 적용합니다.
  - 수익률 양수/음수에 따른 색상(녹색 계열 `emerald-400`, 적색 계열 `rose-400`) 및 아이콘(`ArrowUpRight`, `TrendingDown`) 규칙을 유지합니다.

## Testing Decisions

- **테스트 기준 및 Seam**:
  - 모바일 성과 요약 카드의 최상위 Seam인 컴포넌트 렌더링 및 사용자 인터랙션(`MobilePerformanceSummaryCard.test.jsx`)을 중심으로 테스트합니다.
  - 내부 구현 상태(State)를 직접 검사하지 않고, 렌더링된 텍스트, 탭 버튼 클릭 이벤트, 페이지네이션 버튼 클릭에 따른 화면 변화 등 외부 사용자 관점의 동작만을 검증합니다.
- **주요 검증 항목**:
  1. 초기 렌더링 시 누적 ROI 헤더 및 연도별 기본 탭 데이터가 정상 출력되는지 검증
  2. '월별' 탭 클릭 시 월별 데이터(연월 배지, 수익률, 수익금 등)로 렌더링이 전환되는지 검증
  3. '일별' 탭 클릭 시 일별 데이터(일자 배지 등)로 렌더링이 전환되는지 검증
  4. 데이터가 5개를 초과할 때 페이지네이션 컨트롤이 노출되고, 다음/이전 버튼 클릭 시 항목이 페이지별로 정상 슬라이싱되는지 검증
  5. 탭 전환 시 현재 페이지 번호가 1페이지로 리셋되는지 검증
  6. 마스킹 모드 활성화 시 금액 데이터가 올바르게 마스킹되는지 검증

## Out of Scope

- 시장 지수(KOSPI, S&P 500 등)와의 벤치마크 비교 모드 (모바일 화면 특성상 추후 벤치마크 전용 모바일 화면에서 고려)
- 자산 증가액(increase) 등 복합 지표의 테이블형 그리드 표기 (모바일 뷰 간결성 유지를 위해 제외)
- 백엔드 API 신규 생성 또는 변경 (기존 대시보드 API에서 이미 `yearly`, `monthly`, `daily`를 모두 제공하므로 불필요)

## Further Notes

- 프론트엔드 모바일 라우트(`/mobile/dashboard`)의 전체적인 레이아웃 및 여백과 조화를 이루도록 다크 테마(`bg-slate-900`, `border-slate-800`) 스타일 가이드를 준수합니다.
