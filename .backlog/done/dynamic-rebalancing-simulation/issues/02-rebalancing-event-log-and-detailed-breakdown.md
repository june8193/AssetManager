# 02 — 리밸런싱 이벤트 이력 로그 및 상세 분석 테이블 구현

**What to build:**
사용자가 동적 리밸런싱 시뮬레이션 결과를 확인할 때, 과거 시뮬레이션 기간 동안 실제로 [낙폭 AND VIX] 조건이 충족되어 주식 비중 확대가 발생한 날짜, 당시 지표 수치(S&P 500 종가, 낙폭 %, VIX 수치, 비중 변경 내역) 및 월말 정상 복귀 내역을 표 형태의 '이벤트 로그'로 한눈에 검증하고, 연도별/월별 수익률 및 MDD 상세 통계 테이블을 조회할 수 있는 기능 완성.

**Blocked by:** 01 — 동적 리밸런싱 핵심 시뮬레이션 엔진 및 UI 탭 구현

**Status:** resolved

- [x] 연도별 및 월별 수익률, 연간 MDD 통계 집계 데이터 반환
- [x] 프론트엔드 결과 하단 영역에 탭형 상세 컨테이너 구현 ([이벤트 로그] / [연도별 현황] / [월별 현황])
- [x] 이벤트 로그 테이블에 이벤트 종류별 배지(발동: 주황/빨강, 복귀: 파랑/초록) 및 상세 수치 표시
