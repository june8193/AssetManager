# 02 — 리스크 시각화 2종 차트 탭 및 현금 자동 정산 기반 실시간 매매 시뮬레이터 구현

**Spec:** [spec.md](../spec.md)

**What to build:**
데스크톱 리스크 관리 화면에 접기/펼치기가 가능한 2종 시각화 차트 탭(`[종목별 자체 변동성 vs 기여도]` 바 차트 및 `[벤치마크 대비 낙폭(MDD) 방어력]` 비교 곡선 차트)을 구현하고, 백엔드가 내려준 공분산 행렬과 자산별 일별 수익률 시계열을 활용해 서버 재요청 없이 즉시(0ms) 반응하는 실시간 매매 시뮬레이터를 완성합니다. 시뮬레이터는 슬라이더·금액 직접 입력·빠른 매매 버튼(`-500`, `-100`, `+100`, `+500`, `전량매도`), 매수·매도 차액의 현금 자동 정산 및 현금 부족 경고, 신규 여유자금 추가/인출, 관심종목 및 국내·미국 종목 검색을 통한 미보유 종목 편입 테스트(`extra_tickers` 연동), 3종 정렬(`흔들림 기여도순`, `자체 변동성순`, `보유금액순`), 원클릭 초기화를 지원하며 개발 서버 브라우저 E2E 시나리오로 전체 동작을 검증합니다.

**Blocked by:** 01-volatility-diagnosis-vertical-slice

**Status:** resolved

## Acceptance Criteria

- [x] 시각화 차트 카드에서 `[종목별 자체 변동성 vs 기여도]`(S&P 500·NASDAQ 기준선 표시)와 `[벤치마크 대비 낙폭(MDD) 방어력]`(KOSPI·NASDAQ·S&P 500 대비 현재 및 조정 후 곡선) 탭 전환과 `차트 접기`/`차트 펼치기` 토글이 정상 동작한다.
- [x] 종목별 슬라이더, 금액 직접 입력, 빠른 버튼(`-500`, `-100`, `+100`, `+500`, `전량매도`) 조작 시 서버 재요청 없이 즉시 예상 변동성, 증감 `%p` 배지, 스펙트럼 게이지의 `조정 후` 마커, 일평균 출렁임, S&P 500 대비 배수, 종목별 기여도, MDD 방어력 곡선이 재계산된다.
- [x] 종목 매수/매도 차액이 고정 현금 행의 예상 잔고에 자동 가감되며, 예상 현금이 `0원` 미만으로 내려갈 경우 비중 계산에는 `0`으로 반영하되 상단 요약 바에 현금 부족 경고 배지(`부족 금액` 포함)를 표시한다.
- [x] `여유자금 추가/인출` 입력 및 빠른 버튼(`+500만`, `+1,000만`, `0원`)이 현금 잔고 및 총자산에 즉시 반영되며, `시뮬레이션 초기화` 클릭 시 모든 변경 사항과 추가 종목이 원상 복구된다.
- [x] `+ 미보유/관심종목 편입 테스트`에서 기존 관심종목 목록 및 국내·미국 종목 검색을 통해 신규 티커를 선택하면 백엔드 `extra_tickers` 연동으로 해당 종목을 추가하고 매수 시뮬레이션을 수행할 수 있다.
- [x] 테이블 정렬(`흔들림 기여도순`, `자체 변동성순`, `보유금액순`)이 현금 행 최상단 고정을 유지한 채 정상 동작한다.
- [x] 사전 합의된 프론트엔드 통합 심(`Vitest`) 테스트가 통과하고, 개발 서버(`uv run scripts/dev.py`) 기준 브라우저 E2E 검증 수행 및 스크린샷 저장 후 개발 서버 프로세스가 정상 종료된다.
