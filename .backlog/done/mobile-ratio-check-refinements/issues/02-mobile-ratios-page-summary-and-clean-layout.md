# 02 — 모바일 비중 점검 페이지 시뮬레이션 제거 및 요약 배너 간소화

**What to build:**
모바일 환경에 불필요한 '추가 투자금 시뮬레이션' UI 및 상태를 제거하여 뷰 공간을 확보하고, 상단 '포트폴리오 비중 요약' 배너를 간결하게 개편하여 현재 총 자산과 단일화된 리밸런싱 규모를 한눈에 볼 수 있도록 합니다.

**Blocked by:** 01 — 모바일 비중 카드 종목명 표기 개선 및 리밸런싱 상태 라벨 직관화

**Status:** resolved

- [x] 추가 투자금 증액 시뮬레이션 칩 버튼(100만, 500만, 1,000만 등) 및 초기화 버튼, 관련 상태 로직이 모바일 비중 점검 페이지에서 완전히 제거된다.
- [x] 상단 요약 배너에서 '목표 총 자산' 표시가 제거되고, '현재 총 자산'이 단일 메인 금액으로 돋보이게 렌더링된다.
