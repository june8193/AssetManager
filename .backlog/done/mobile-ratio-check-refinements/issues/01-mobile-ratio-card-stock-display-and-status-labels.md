# 01 — 모바일 비중 카드 종목명 표기 개선 및 리밸런싱 상태 라벨 직관화

**What to build:**
모바일 비중 카드에서 주식 종목을 볼 때 숫자 티커 대신 종목명이 메인으로 돋보이고 티커가 보조로 병기되도록 개선합니다. 또한 포트폴리오 리밸런싱 관점에서 '초과'/'추가 매수' 상태명을 '매도 필요'/'매수 필요'로 직관화하고, 목표 비중이 설정되지 않은 자산(0% 이하)은 불필요한 매도 경고나 배지가 노출되지 않도록 처리합니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 주식 레벨 아이템 표시 시 종목 이름(`name`)이 메인 볼드로 노출되고, 티커(`ticker`)가 종목명과 다를 경우 옆에 `(티커)` 형태로 보조 병기된다.
- [x] 목표 비중이 설정된 자산에 대해 상태 배지가 '매수 필요'(Sky), '매도 필요'(Amber), '적정'(Emerald)으로 명확히 구분되어 표시된다.
- [x] 카드 하단의 조정 필요 금액 텍스트가 '매수 필요 +X원', '매도 필요 -X원'으로 일관되게 표시된다.
- [x] 목표 비중이 0%이거나 미설정된 자산은 상태 배지, 편차(%p), 리밸런싱 필요 금액 영역이 노출되지 않고 현재 평가액과 비중만 깔끔하게 표시된다.
- [x] 목표 미설정 자산의 목표 비중 표시 영역에는 '-'가 노출되고 게이지 바는 현재 비중만 반영한다.
- [x] 모바일 비중 카드 단위 테스트(`MobileRatioCard.test.jsx`)에 위 요구사항이 모두 반영되어 정상 통과한다.
