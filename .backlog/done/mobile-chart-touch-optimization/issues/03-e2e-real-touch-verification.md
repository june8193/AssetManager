# 03 — 모바일 실기기 뷰포트 CDP 터치 슬라이드 연속 추종 및 무잔상 E2E 검증

**What to build:** 개발 서버 환경에서 모바일 실기기 뷰포트(390×844)로 접속하여 실제 연속 터치 슬라이드(CDP touchStart → 연속 touchMove → touchEnd) 시 세로선 연속 추종 및 터치 해제 시 즉각 소멸이 완벽히 작동함을 Playwright 자동화로 검증하고 스크린샷 기록을 확보하는 작업.

**Blocked by:** 02 — SVG 영역 채우기(Area) 포인터 간섭 차단 및 3대 차트 일괄 적용 (pointer-events-none)

**Status:** resolved

- [x] 개발 서버(`uv run scripts/dev.py`) 환경에서 모바일 뷰포트(390×844) E2E 검증이 성공한다.
- [x] 지수 종가 차트에서 touchStart 즉시 첫 지표 데이터가 인스펙터에 표시된다.
- [x] 10회 이상의 연속 터치 슬라이드 동안 데이터 갱신 누락 없이 실시간으로 지표가 추종된다.
- [x] 터치 종료 후 즉시 플레이스홀더로 복귀하고 세로선이 남지 않는다.
- [x] 검증 스크린샷이 `screenshots/` 디렉토리에 정상 저장되고 개발 서버가 안전하게 종료된다.
