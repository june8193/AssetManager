# 04 — 업로드 미리보기 연동 및 E2E 브라우저 교차 검증

**What to build:** 
실제 개발 서버(`uv run scripts/dev.py`) 환경에서 자동분류 규칙을 등록하고, 명세서 파일을 업로드하여 미리보기 테이블에 규칙이 정상 반영되는지, 사용자가 개별 항목을 수동 수정한 뒤 최종 커밋했을 때 DB에 안전하게 반영되는지 전체 E2E 시나리오를 브라우저로 통합 검증하고 확인 스크린샷을 기록합니다.
