# 02 — VIX 4단계 기준선 및 상태 배지 UI 구현

**What to build:** VIX 차트 상에 4단계 시장 심리 기준선(20, 30, 40)을 텍스트 라벨과 함께 시각화하고, 차트 카드 우측 상단에 최근 VIX 수치 및 위험도에 대응하는 색상 상태 배지(안정/주의/경고/위기)를 동적으로 표시하여 한눈에 시장 리스크를 파악할 수 있는 UI.

**Blocked by:** 01 — 백엔드 VIX 연동 및 기본 차트 동기화 슬라이스

**Status:** resolved

- [x] VIX 차트에 Y축 기준선 20(주의), 30(경고), 40(위기) 대시선(ReferenceLine)이 표시된다.
- [x] 각 기준선 우측 또는 좌측에 직관적인 라벨 텍스트(예: 주의 20, 경고 30, 위기 40)가 렌더링된다.
- [x] 차트 카드 헤더 우측에 최근 VIX 종가 수치가 표시된다.
- [x] 최근 VIX 수치에 따라 4단계 상태 배지가 동적 스타일링으로 표시된다:
  - 20 미만: 안정 (`#10B981`, Green)
  - 20 이상 30 미만: 주의 (`#F59E0B`, Amber)
  - 30 이상 40 미만: 경고 (`#EF4444`, Red)
  - 40 이상: 위기 (`#991B1B`, Deep Crimson)
- [x] 관련 컴포넌트 단위 테스트가 통과한다.
