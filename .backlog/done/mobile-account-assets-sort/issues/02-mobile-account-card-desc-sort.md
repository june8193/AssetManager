# 02 — 모바일 웹 계좌별 자산 아코디언 보유종목 내림차순 렌더링 및 테스트

**What to build:** 모바일 웹 '자산 조회' 탭의 계좌별 자산 카드에서 계좌 아코디언을 클릭해 펼쳤을 때, 보유 종목들이 평가금액(KRW)이 큰 순서부터 아래로(내림차순) 표시되도록 렌더링을 구현합니다. 평가금액이 동일한 경우 종목명 가나다순으로 배치되며, 마스킹 모드 및 실시간 시세 갱신 시에도 올바른 정렬 상태가 유지되도록 합니다.

**Blocked by:** 01 — 백엔드 대시보드 요약 API 계좌별 보유종목 평가금액 내림차순 사전 정렬

**Status:** resolved

- [x] 모바일 계좌 카드 컴포넌트에서 보유 종목 리스트가 1차 `valuation_krw` 내림차순, 2차 `name` 오름차순으로 정렬되어 렌더링된다.
- [x] 예수금(현금 자산)도 일반 종목과 함께 금액 크기순으로 동일하게 정렬되어 표시된다.
- [x] 금액 마스킹(***) 모드가 활성화되어도 정렬 순서가 흐트러지지 않는다.
- [x] Vitest 및 React Testing Library 단위 테스트에서 다양한 평가액/종목명을 가진 계좌의 종목 렌더링 순서가 검증된다.
- [x] 개발 서버 실행 및 브라우저 검증을 통해 모바일 UI에서 보유 종목들이 금액순으로 배치됨을 확인한다.
