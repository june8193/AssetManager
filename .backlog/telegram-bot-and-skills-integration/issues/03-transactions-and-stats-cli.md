# 03 — 거래내역 및 일별/연간 통계 조회 (/tx, /daily, /yearly) CLI 슬라이스

**What to build:**
사용자가 텔레그램에서 최근 체결된 거래 내역(`/tx [개수]`), 연도별 자산 성장 및 수익률(`/yearly`), 그리고 최근 일별 스냅샷 자산 변화 추이(`/daily [일수]`)를 조회하여 과거 투자 히스토리와 단기 자산 변동을 모바일에서 즉시 확인할 수 있는 E2E 슬라이스를 구축합니다.

**Blocked by:** 02 — 자산 총액 및 비중 조회 (/asset, /ratio) CLI 슬라이스

**Status:** resolved

- [x] 로컬 REST API의 거래내역(`/api/transactions`), 연간 통계(`/api/dashboard/yearly`), 일별 스냅샷 통계(`/api/snapshots`) 조회 엔드포인트 연동이 구현된다.
- [x] `/tx` 또는 `/transactions` 수신 시 기본 5개(또는 파라미터로 지정된 N개)의 최근 거래 내역(일자, 종목명, 매매구분, 단가, 수량, 총금액)이 렌더링되어 응답된다.
- [x] `/yearly` 수신 시 연도별 자산 총액, 연간 수익금 및 수익률, 배당금 내역이 요약 응답된다.
- [x] `/daily` 수신 시 기본 7일(또는 파라미터로 지정된 N일) 동안의 일별 자산 평가액 및 전일 대비 증감 현황이 응답된다.
- [x] 거래내역 및 일별/연간 통계 데이터 렌더링과 파라미터 파싱 처리를 검증하는 단위 테스트가 통과한다.
