# 02 — 자산 총액 및 비중 조회 (/asset, /ratio) CLI 슬라이스

**What to build:**
사용자가 텔레그램에서 `/asset` 또는 `/ratio` 명령어를 입력했을 때, 백엔드 로컬 REST API 엔드포인트를 호출하여 현재 총자산 평가액, 누적 투자 수익률, 대/소분류 자산 비중 및 목표 비중 대비 리밸런싱 현황을 모바일 최적화 마크다운 형식으로 수신하는 E2E 슬라이스를 구축합니다.

**Blocked by:** 01 — 텔레그램 기반 설정 및 기본 /help 핑퐁 슬라이스

**Status:** resolved

- [x] 로컬 FastAPI REST API(`/api/dashboard`, `/api/ratios`)를 비동기로 호출하는 `asset_client` 모듈이 연동된다.
- [x] 수신된 자산 데이터를 모바일 화면에 맞게 표 서식 대신 불릿과 이모지 형태로 변환하는 마크다운 렌더러가 동작한다.
- [x] 텔레그램에서 `/asset` 명령어 수신 시 총 평가액, 누적 수익금, 수익률이 포함된 요약 메시지가 응답된다.
- [x] 텔레그램에서 `/ratio` 명령어 수신 시 자산군별 현재 비중, 목표 비중, 리밸런싱 조정 금액이 포함된 메시지가 응답된다.
- [x] 명령어 처리 중 Typing 액션(`sendChatAction`)이 전송되어 사용자에게 진행 상태를 시각적으로 알린다.
- [x] REST API 응답을 모킹하여 `/asset` 및 `/ratio` 커맨드 응답 포맷팅과 에러 처리를 검증하는 단위 테스트가 통과한다.
