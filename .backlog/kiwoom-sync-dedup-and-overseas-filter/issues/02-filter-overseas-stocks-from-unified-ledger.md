# 02 — 종합원장 소급 주식 매매 파서에서 해외주식 0달러 적재 필터링

**What to build:**
종합원장(`kt00015`)의 소급 주식 매매(`is_retroactive`) 파서에서 원화 거래금액이 0원이거나 외화 거래금액이 존재하는 해외주식 거래를 원천 제외합니다. 해외주식 매매는 오직 미국 전용 체결 API(`ust21510`)만을 통해 정상 단가(USD)로 수집되도록 책임을 명확히 분리하여, 0달러 매수/매도 거래가 DB에 이중 적재되는 문제를 방지합니다.

**Blocked by:** 01 — 원장 거래 external_id 일자 결합 및 중복 검증 일자 조건 보강

**Status:** ready-for-agent

- [ ] 종합거래내역(`kt00015`)에서 매매 적요(`매수`, `매도` 등)를 처리할 때, 원화 거래금액(`trde_amt`)이 0 이하이거나 외화 거래금액(`fc_trde_amt`)이 0 초과인 거래는 주식 매매 파싱 대상에서 제외된다.
- [ ] 거래소명(`stex_nm`)이 '미국' 등 해외 거래소이거나 종목코드(`stk_cd`)가 6자리 숫자가 아닌 해외 티커인 경우 종합원장 매매 파싱 대상에서 제외된다.
- [ ] 종합원장에 해외주식 매수 내역(원화 0원, 외화 체결금액 존재)과 미국 전용 체결 API에 동일 종목 매수 내역이 동시에 존재할 때, 0달러 거래는 생성되지 않고 오직 미국 전용 체결 API의 정상 거래 1건만 저장된다.
- [ ] 정상적인 국내 주식 매매(원화 금액 > 0, 6자리 숫자 종목코드)는 기존과 동일하게 종합원장에서 정상적으로 파싱 및 저장된다.
