# 04 — 브라우저 E2E 통합 검증 및 시나리오 테스트

**What to build:**
실제 개발 서버 환경에서 사용자가 동적 리밸런싱 탭에 진입하여 거치식/적립식 모드 전환, 다단계 트리거 조건 편집, 프리셋 저장/불러오기/수정/삭제, 3개 벤치마크 차트 및 리밸런싱 이벤트 로그 확인에 이르는 전체 사용자 경험(User Journey)을 브라우저 상에서 매끄럽게 수행할 수 있음을 검증하고 화면 스크린샷 기록을 남기는 E2E 통합 검증 완성.

**Blocked by:** 02 — 리밸런싱 이벤트 이력 로그 및 상세 분석 테이블 구현, 03 — 다단계 트리거 동적 편집 및 전략 프리셋 영구 관리(CRUD) 구현

**Status:** ready-for-agent

- [ ] 백엔드 및 프론트엔드 전체 단위/통합 테스트 스위트 통과 (`pytest`, `vitest`)
- [ ] 개발 서버(`uv run scripts/dev.py`) 구동 후 브라우저 환경에서 시나리오별 E2E 검증 실행
- [ ] 시나리오 1: 동적 리밸런싱 탭 진입 및 기본 프리셋 결과 차트/카드/로그 렌더링 확인
- [ ] 시나리오 2: 단계 추가/삭제 및 조건 수치 변경 시 시뮬레이션 즉각 재계산 확인
- [ ] 시나리오 3: 커스텀 프리셋 저장 -> 수정 -> 다른 프리셋 전환 -> 삭제 동작 정상 여부 검증
- [ ] 시나리오 4: 거치식 vs 적립식 모드 전환 및 결과 검증
- [ ] 주요 화면 검증 스크린샷 저장 (`screenshots/YYYYMMDD_HHMMSS_dynamic_rebalancing_simulation/`) 및 개발 서버 정상 종료
