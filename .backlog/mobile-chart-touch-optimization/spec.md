# 모바일 시장 지수 차트 터치 인터랙션 최적화 및 슬라이드 세로선 실시간 추종 명세서

Status: ready-for-agent

## Problem Statement

모바일 환경에서 시장 지수 분석 화면을 이용하는 사용자가 지수 종가 차트를 터치(탭)하거나 좌우로 슬라이드할 때, 세로선(커서)과 상단 인스펙터 바가 자연스럽게 이동하지 않고 멈추거나 튕기며 클릭 반응이 정상적으로 작동하지 않습니다.

반면 동일한 페이지 내의 낙폭(MDD) 차트와 VIX 변동성 차트에서는 터치 슬라이드가 부드럽게 작동하여, 사용자에게 일관되지 못하고 뻑뻑한 조작감을 제공합니다. 이는 지수 종가 차트의 거대한 SVG 면적 채우기(Area Fill) 요소가 캔버스의 대부분을 덮어 모바일 브라우저의 터치 이벤트를 가로채고, 터치 시작(touchStart) 이벤트 처리 누락 및 캔버스 영역의 브라우저 기본 스크롤 제스처 개입이 복합적으로 작용하여 발생하는 문제입니다.

## Solution

1. 차트 영역 내 터치 시작(touchStart) 및 이동(touchMove) 시점에 즉각적으로 터치 좌표를 감지하여 세로선 안내선과 상단 인스펙터 바가 지체 없이 부드럽게 손가락을 따라 이동하도록 이벤트 파이프라인을 정비합니다.
2. 사용자가 손가락을 떼는 순간(touchEnd / touchCancel)에는 세로선과 인스펙터 바가 즉시 소멸하여 차트 곡선을 일체 가리지 않는 기존의 초슬림 규격을 엄격히 유지합니다.
3. 차트 캔버스 영역에 `touch-action: none` 규칙을 적용하여 슬라이드 탐색 중 브라우저 세로 스크롤 개입 및 터치 취소(touchcancel)를 원천 차단합니다.
4. 차트 면적 채우기(Area Fill) SVG 요소의 포인터 이벤트 간섭을 차단하여, 화면 전체에서 터치 좌표가 배경 캔버스로 직통 전달되도록 개선합니다.
5. 이 최적화를 지수 종가, MDD, VIX 3대 차트 전체에 동일하게 일괄 적용하여 모바일 지수분석 전반의 조작 일관성을 완성합니다.

## User Stories

1. 모바일 투자자로서, 지수 차트의 임의의 지점을 손가락으로 탭했을 때 즉시 해당 날짜의 세로선과 지표 수치(지수, MDD, VIX)가 상단 인스펙터 바에 노출되기를 원하며, 이를 통해 원하는 시점의 시장 상태를 즉각 확인하고 싶다.
2. 모바일 투자자로서, 지수 차트 위에서 손가락을 좌우로 슬라이드(스크러빙)할 때 세로선이 손가락의 움직임에 맞춰 1밀리초의 끊김도 없이 부드럽게 따라오기를 원하며, 이를 통해 과거 추이를 직관적으로 탐색하고 싶다.
3. 모바일 투자자로서, 지수 차트를 슬라이드하는 도중 손가락이 위아래로 미세하게 흔들리더라도 화면 스크롤이 제스처를 가로채지 않기를 원하며, 이를 통해 의도치 않은 터치 튕김 없이 안정적으로 차트를 훑어보고 싶다.
4. 모바일 투자자로서, 차트 탐색을 마치고 화면에서 손가락을 떼는 순간 세로선과 인스펙터 수치가 즉시 사라지기를 원하며, 이를 통해 잔상이나 불투명 팝업 없이 깔끔한 지수 곡선 전체를 감상하고 싶다.
5. 모바일 투자자로서, 지수 종가 탭뿐만 아니라 MDD 탭과 VIX 변동성 탭에서도 완전히 동일한 터치 감도와 매끄러운 세로선 추종을 경험하기를 원하며, 이를 통해 탭 전환 시에도 이질감 없는 통일된 조작감을 얻고 싶다.
6. 모바일 투자자로서, 차트 영역 밖(헤더, 탭 스위처, 하단 극단값 카드 영역 등)을 터치하여 스크롤할 때는 페이지 전체가 자연스럽게 상하로 스크롤되기를 원하며, 이를 통해 페이지 전체 콘텐츠를 편안하게 탐색하고 싶다.

## Implementation Decisions

1. **차트 캔버스 제스처 제어**:
   - 차트 캔버스 컨테이너에 `touch-action: none` 스타일을 지정하여 차트 내부에서의 터치 슬라이드 동작이 브라우저의 기본 세로 스크롤 엔진에 의해 취소(`touchcancel`)되거나 가로채이지 않도록 격리합니다.
   - 텍스트 선택 방지(`user-select: none`)를 병행하여 드래그 중 의도치 않은 텍스트 블록 선택을 방지합니다.

2. **이벤트 파이프라인 정비 (터치 시작 바인딩)**:
   - 기존의 `touchMove` 및 `mouseMove` 핸들러 외에, `touchStart` 이벤트 발생 시에도 동일한 좌표 갱신 로직을 즉시 실행하여 탭하는 순간 첫 포인트의 지표가 상단 바에 표출되도록 바인딩합니다.
   - 손가락을 떼는 `touchEnd` 및 `touchCancel` 이벤트 발생 시에는 툴팁 상태를 `null`로 초기화하여 즉시 소멸시키는 기존의 무잔상 규격을 유지합니다.

3. **SVG 영역 채우기 포인터 이벤트 차단**:
   - 차트 면적 채우기(Area) SVG 패스가 마우스/터치 이벤트를 흡수하거나 제스처 판정을 왜곡하지 않도록 포인터 이벤트를 비활성화(`pointer-events: none`)합니다.
   - 이를 통해 화면 어디를 터치하든 터치 이벤트의 direct target이 루트 SVG 표면으로 일관되게 전달되도록 보장합니다.

4. **3대 서브탭 차트 일괄 적용**:
   - 지수 종가(Price), 최대 낙폭(MDD), VIX 변동성(VIX) 차트 컴포넌트 전체에 동일한 캔버스 제스처 속성 및 터치 이벤트 핸들러를 일괄 적용합니다.

## Testing Decisions

1. **테스트 품질 기준**:
   - 내부 상태나 SVG 내부 DOM 구조에 의존하지 않고, 사용자의 실제 터치 인터랙션(터치 시작, 슬라이드 이동, 터치 종료)에 따른 외부 관측 동작(인스펙터 바 노출, 실시간 날짜 갱신, 종료 시 즉각 소멸)만을 검증합니다.

2. **테스트 모듈 및 Seam**:
   - **단위 테스트 (Vitest)**: 모바일 지수 컴포넌트 단위에서 `touchStart` 발생 시 인스펙터 바 렌더링, `touchEnd` 발생 시 즉각 플레이스홀더 복귀, 캔버스 컨테이너의 터치 제어 클래스 적용 여부를 검증합니다.
   - **실기기 뷰포트 E2E 테스트 (Playwright)**: 모바일 뷰포트(390×844) 환경에서 CDP(Chrome DevTools Protocol) 합성 터치 이벤트를 전송하여, 지수 종가 차트 위를 10단계 연속 슬라이드할 때 실시간으로 데이터가 누락 없이 연속 갱신되는지, 손을 뗀 후 즉각 소멸하는지 종단간 검증합니다.

3. **기존 테스트 자산 참조**:
   - `MobileMarketIndexSection.test.jsx`의 통합 초슬림 인스펙터 바 검증 테스트 케이스를 기반으로 터치 시작 및 제스처 속성 검증을 확장합니다.

## Out of Scope

- 데스크톱 화면(`/market`)의 3단 통합 차트 인터랙션 수정 (모바일 전용 최적화에 집중).
- 툴팁을 화면에 고정 노출하는 별도의 핀(Pin) 모드 또는 닫기(X) 버튼 추가.
- 차트 줌인/줌아웃 핀치(Pinch) 제스처 기능.
