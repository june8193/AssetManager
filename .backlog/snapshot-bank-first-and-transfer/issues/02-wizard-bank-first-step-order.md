# 02 — 스냅샷 생성 위저드 5단계 진행 순서를 '현금계좌(은행) → 주식계좌(증권)'로 변경

**Spec:** [spec.md](../spec.md)

**What to build:** 스냅샷 생성 위저드의 5단계 흐름을 1단계(기본 정보/은행 선택) → 2단계(은행 상세 입력) → 3단계(증권 계좌 선택) → 4단계(증권 상세 입력) → 5단계(최종 확인, 은행→증권 순 표시)로 변경하고, 단계 이동(다음/이전/건너뛰기) 및 유효성 검사를 새 순서에 맞게 동작시키는 프론트엔드 기능.

**Blocked by:** `01-backend-bank-first-and-transfer-pair`

**Status:** closed

- [x] 1단계에서 선택된 은행 계좌가 없을 경우 건너뛰기 확인창(`선택된 은행 계좌가 없습니다. 은행 단계를 건너뛰시겠습니까?`)을 거쳐 3단계(증권 계좌 선택)로 이동한다.
