# 04 — 지출 모니터링 대시보드(소유주 탭, KPI, 차트) 및 거래 원장 관리 화면

**What to build:** 
사이드바에 '지출 관리' (`/expenses`) 메뉴를 추가하고, 상단 소유주 탭(`전체보기 / 장준 / 성은`), 월별 총지출 KPI 카드, 월별 지출 추이 바차트, 카테고리 비중 도넛차트, 결제수단별 요약 카드 및 필터/검색/인라인 수정/삭제가 가능한 상세 거래 원장 테이블을 렌더링하는 엔드투엔드 화면을 제공합니다.

**Blocked by:** 
- 01 — 지출 DB 스키마 구축 및 결제수단/카테고리 관리 기능
- 03 — 명세서 드래그앤드롭 업로드, 프리뷰 검토 및 덮어쓰기 등록 기능

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 좌측 사이드바에 '지출 관리' 메뉴 아이콘과 라우트(`/expenses`)가 추가되어 클릭 시 지출 관리 페이지로 이동한다.
- [ ] 상단 소유주 탭(`전체`, `장준`, `성은`) 선택 시 대시보드 통계 지표와 거래 목록이 해당 소유주의 데이터로 즉시 반응하여 필터링된다.
- [ ] 당월 총지출 KPI 카드, 최근 6~12개월 월별 지출 추이 바차트, 당월 카테고리별 비중 도넛차트가 Recharts를 통해 미려하게 시각화된다.
- [ ] 결제수단별(장준 현대카드, 장준 카카오뱅크 등) 지출 요약 카드가 표시된다.
- [ ] 하단 거래 원장 테이블에서 년월 필터, 소유주 필터, 카테고리 필터, 결제기관 필터 및 검색이 동작한다.
- [ ] 테이블에서 거래건의 카테고리 인라인 변경, 통계 제외 여부 토글, 개별 삭제 액션이 백엔드 API와 연동되어 즉시 반영된다.
- [ ] 프론트엔드 컴포넌트 단위 테스트(`ExpensesPage.test.jsx`)가 정상 통과한다.
