# 03 — 명세서 드래그앤드롭 업로드, 프리뷰 검토 및 덮어쓰기 등록 기능

**What to build:** 
웹 화면에서 명세서 파일(카카오뱅크/현대카드)을 드래그앤드롭으로 업로드하면 복호화 파서를 거쳐 추출된 거래 목록을 프리뷰 모달에 띄우고, 사용자가 카테고리 지정 및 카드대금 출금건에 대한 '통계 제외'를 체크한 뒤 [DB 등록] 클릭 시 동일 청구월/결제수단의 기존 데이터를 통째로 덮어쓰기(대체) 저장하는 엔드투엔드 흐름을 제공합니다.

**Blocked by:** 
- 01 — 지출 DB 스키마 구축 및 결제수단/카테고리 관리 기능
- 02 — 카카오뱅크 및 현대카드 명세서 자동 복호화 파서 파이프라인

**Status:** ready-for-agent

## Acceptance criteria

- [ ] `POST /api/expenses/upload-preview` 엔드포인트를 통해 파일을 업로드하면 DB 저장 없이 파싱된 거래 목록, 청구년월, 매칭된 결제수단 정보를 반환한다.
- [ ] 결제수단에 등록된 기본 비밀번호 또는 사용자가 모달에 입력한 비밀번호로 복호화가 수행된다.
- [ ] 업로드 검토 모달에서 추출된 전체 거래 행이 표로 표시되며, 각 행마다 카테고리 드롭다운과 '통계 제외' 체크박스를 조작할 수 있다.
- [ ] `POST /api/expenses/commit` 엔드포인트를 통해 사용자가 수정한 프리뷰 데이터를 전송하면, 해당 년월(`year_month`) 및 결제수단(`payment_method_id`)의 기존 지출 레코드를 모두 삭제하고 새 데이터로 대체 적재한다.
- [ ] 동일한 파일 또는 동일한 청구월 파일을 재업로드했을 때 데이터가 중복 누적되지 않고 정확히 덮어쓰기됨을 검증하는 테스트가 통과한다.
