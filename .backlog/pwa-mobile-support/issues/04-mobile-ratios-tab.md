# 04 — 모바일 비중 점검 탭 (목표비중 및 리밸런싱)

**What to build:**
모바일 기기에서 자산군별 목표 비중 대비 현재 비중 및 리밸런싱 필요 금액을 확인할 수 있는 `MobileRatiosPage`를 구현합니다. 기존 `useRatios` 훅의 계산 로직을 100% 재사용하여, 카테고리별 현재 평가액/비중, 목표 비중, 편차(%), 추가 매수/매도 필요 금액을 직관적인 모바일 카드 리스트로 시각화합니다. 설정 변경 폼 없이 읽기 전용으로 안전하게 제공합니다.

**Blocked by:** 01 — PWA 인프라 및 적응형 모바일 레이아웃 쉘

**Status:** ready-for-agent

- [ ] `MobileRatiosPage` 컴포넌트가 구현되고 모바일 비중 점검 탭(`/m/ratios`)에 연결되어야 함
- [ ] `useRatios` 훅의 데이터를 기반으로 자산군별 현재 비중, 목표 비중, 편차, 리밸런싱 금액이 모바일 카드 형태로 명확히 렌더링되어야 함
- [ ] 비중 수정 폼 없이 순수 조회 전용으로 동작해야 함
- [ ] 마스킹 토글 시 현재 평가액 및 리밸런싱 금액이 마스킹되어야 함
- [ ] 모바일 비중 점검 컴포넌트에 대한 단위 테스트가 작성되고 통과해야 함
