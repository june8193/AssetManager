# 02 — 스냅샷 위저드 저장 시 누락 일자 자동 연속 산출 및 저장 (Continuous Snapshot Backfill on Save)

**What to build:** 스냅샷 마법사(Wizard)에서 최종 저장을 실행할 때, 직전 스냅샷 기준일 익일부터 오늘까지의 모든 캘린더 날짜(주말/공휴일 포함)에 대해 일별 원장 거래내역 리플레이 및 일별 역사적 시세/환율(Forward-fill 적용)을 기반으로 스냅샷을 연속 자동 산출하여 원자적으로 단일 트랜잭션에 저장하는 엔드투엔드 기능.

**Blocked by:** 01 — 스냅샷 다중 선택 및 일괄 삭제 (Batch Delete with Shift-Click)

**Status:** ready-for-agent

- [ ] 직전 스냅샷이 존재하는 상태에서 스냅샷 저장 시, 직전 스냅샷 익일부터 저장 기준일까지의 모든 날짜(캘린더 일자 전체)에 대해 스냅샷이 생성된다.
- [ ] 각 중간 일자별로 해당 일자까지의 원장 거래내역이 리플레이되어 계좌별 보유수량 및 현금 잔고가 정확히 반영된다.
- [ ] 각 중간 일자별 자산 평가 시 HistoricalPrice 및 ExchangeRate가 적용되며, 비영업일(주말/공휴일)이나 누락 시 직전 유효 종가/환율(Forward-fill)이 사용된다.
- [ ] 오늘 입력된 신규 거래 및 잔고 차액 보정(CASH_ADJUSTMENT)은 오늘(기준일) 스냅샷에만 반영되고 과거 중간 날짜에는 영향을 주지 않는다.
- [ ] 모든 날짜의 스냅샷 저장이 단일 DB 트랜잭션으로 원자적으로 커밋된다.
- [ ] 백엔드 단위/통합 테스트가 작성되고 모두 통과한다.
