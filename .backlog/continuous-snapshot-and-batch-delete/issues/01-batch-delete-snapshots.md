# 01 — 스냅샷 다중 선택 및 일괄 삭제 (Batch Delete with Shift-Click)

**What to build:** DB 관리 > 스냅샷 탭에서 테이블 체크박스 및 Shift + 클릭 범위 선택을 통해 여러 날짜의 스냅샷을 한 번에 선택하고, 상단 '선택 삭제' 버튼을 눌러 단일 트랜잭션으로 스냅샷 및 관련 보정 거래(CASH_ADJUSTMENT)를 일괄 삭제하는 엔드투엔드 기능.

**Blocked by:** None — can start immediately

**Status:** claimed

- [x] DB 관리 스냅샷 테이블의 헤더에 전체 선택/해제 체크박스가 표시된다.
- [x] 각 스냅샷 행에 개별 선택 체크박스가 표시된다.
- [x] 한 행을 체크한 뒤 Shift 키를 누르고 다른 행을 클릭하면 그 사이의 모든 행이 한 번에 범위 선택된다.
- [x] 1개 이상의 스냅샷이 선택되면 상단 툴바에 '선택 삭제 (N개)' 버튼이 활성화된다.
- [x] '선택 삭제' 버튼 클릭 시 확인 알림창이 표시되고, 확인 시 백엔드 일괄 삭제 API를 호출하여 선택된 모든 날짜의 스냅샷과 CASH_ADJUSTMENT 트랜잭션이 한 번에 삭제된다.
- [x] 삭제 완료 후 스냅샷 목록이 자동으로 새로고침된다.
- [x] 백엔드 및 프론트엔드 자동화 테스트가 작성되고 모두 통과한다.
