# Spec: 다중 클라이언트(MCP·Telegram·CLI) 이음새 정립 및 1,363줄 지출 라우터 심화

Status: ready-for-agent

## Problem Statement (문제 정의)

FastAPI와 동일한 프로세스·이벤트 루프에서 실행되는 텔레그램 봇과 장마감 스케줄러가 인프로세스 도메인 모듈 대신 자기 자신의 로컬 HTTP 엔드포인트(`localhost:8000`)로 루프백 요청을 보내고 있으며, MCP 서버와 텔레그램 클라이언트가 동일 백엔드 응답 모델과 HTTP 래퍼를 2벌로 중복 유지하고 있다. 또한 백엔드 조회 응답이 불완전하여 텔레그램 관심종목 조회 시 종목명이 빈 문자열(`""`)로 증발하고, MCP 리스크·지출 도구로 파생 지표 계산 및 `total_count` 왜곡(페이징 길이를 전체 건수로 오보고)이 누수되었다. 한편 지출 도메인은 전용 도메인 모듈 없이 1,363줄의 라우터 파일 안에 자동분류·덮어쓰기 커밋·동기간 통계·PDF 이중 복호화가 혼재되어 있다.

## Solution (해결 방안)

지출 원장·규칙 매칭·동기간 통계 및 PDF 단일 복호화 파이프라인을 깊은 지출 도메인 모듈로 추출하여 지출 라우터를 얇은 HTTP 어댑터로 축소한다. 이어서 관심종목 시세 응답에 종목명을 포함시키고 리스크 파생 지표·지출 필터 및 전체 건수(`total_count`)를 백엔드 인터페이스에 포함시킨다. 마지막으로 중립적인 `AssetQueryPort` 이음새를 정의하고, 인프로세스 어댑터(텔레그램 봇·스케줄러)와 단일 원격 HTTP 어댑터(MCP 서버·원격 CLI) 두 어댑터를 연결해 자기 자신 HTTP 루프백을 제거한다.

## User Stories (사용자 스토리)

1. As an 텔레그램 봇 사용자, I want 관심종목 시세 조회 시 종목명이 누락되지 않고, 동일 프로세스 내 백엔드 포트 설정이 바뀌어도 루프백 통신 장애 없이 동작하기를, so that 텔레그램 명령과 장마감 알림이 안정적으로 실행된다.
2. As an MCP 에이전트 사용자, I want 지출 조회 시 카테고리명 필터와 정확한 전체 건수(`total_count`)가 반환되고, 리스크·관심종목 조회 시 클라이언트 재조립이나 다중 왕복 없이 완성된 지표가 반환되기를, so that 자산 자문과 감사 시 잘못된 수치로 판단하지 않는다.
3. As an 백엔드 개발자, I want 지출 자동분류 규칙·다중월 덮어쓰기 커밋·PDF 복호화 파이프라인이 HTTP 계층과 분리된 깊은 도메인 모듈로 존재하기를, so that Multipart 업로드 픽스처 없이 인메모리 DB만으로 지출 도메인을 고속 검증할 수 있다.

## Implementation Decisions (구현 결정사항)

- **지출 도메인 모듈 추출 및 PDF 단일 복호화**: 가맹점 키워드 우선순위 매칭, 기관 일치 검증, 다중 청구월 원자적 덮어쓰기 커밋, 미분류 거래 차단, 전기간 대비(MoM) 및 12개월 추이 통계를 지출 도메인 모듈로 분리한다. 암호화 PDF 명세서는 기관 판별과 파싱 과정에서 1회만 복호화·텍스트 추출하도록 파이프라인을 단일화한다.
- **백엔드 조회 인터페이스 심화**: 관심종목 시세 응답에 종목명을 기본 포함하고, 리스크 변동성 응답에 포트폴리오 `max_mdd`·`risk_weight_ratio`·`top_risk_contributors`를 기본 산출하며, 지출 조회 엔드포인트에 카테고리명 필터와 실제 전체 매칭 건수(`total_count`)를 포함한다.
- **진짜 이음새(`AssetQueryPort`)와 2개 어댑터**: 텔레그램 패키지 바깥에 중립 조회 포트를 두고, ① 인프로세스 어댑터(텔레그램 봇·장마감 스케줄러용 직접 도메인 호출), ② 단일 원격 HTTP 어댑터(MCP 서버용 커넥션 풀 재사용 및 백엔드 스키마 공유)를 구현한다.

## Testing Decisions (테스트 결정사항)

- **검증 기준**: HTTP 문자열 수동 모킹 대신 지출 도메인 인터페이스 및 `AssetQueryPort` 양대 어댑터를 통해 실제 계약 정합성을 검증한다.
- **사전 합의된 테스트 심 (Pre-agreed Seams)**:
  - 지출 도메인 모듈 공개 인터페이스 + 인메모리 SQLite: **Catches** 자동분류 우선순위, 다중월 덮어쓰기 원자성, 직전 동기간 MoM 증감률, PDF 이중 복호화 회귀 / **Misses** HTTP Multipart 업로드 헤더 파싱
  - `AssetQueryPort` 양대 어댑터(인프로세스 어댑터 + `ASGITransport` HTTP 어댑터): **Catches** 텔레그램 루프백 의존, 관심종목명 `""` 증발, 지출 `total_count` 왜곡 / **Misses** 실제 텔레그램 Bot API 네트워크 장애
- **참고할 기존 테스트 패턴**: `tests/test_expense_upload_flow.py`, `tests/test_mcp_benchmark.py`, `tests/test_telegram_tx_stats.py`.

## Out of Scope (범위 제외 사항)

- 서버 PC 로컬 배치 CLI(뉴스 조회, 저장 경로, 텔레그램 발송)의 MCP 전환(ADR-0001에 따라 로컬 CLI 유지).
- 호출자 없는 고아 CLI 스크립트 4종 삭제(별도 피처 `agent-skills-cli-cleanup-and-adr`에서 다룸).
