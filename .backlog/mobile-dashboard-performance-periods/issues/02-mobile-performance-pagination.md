# 02 — 모바일 성과 요약 카드 월별/일별 페이지네이션 및 탭 전환 연동

**What to build:** 월별 및 일별 성과 데이터가 5개를 초과할 때 모바일 화면에서 한 번에 5개씩 깔끔하게 표시되고, 하단 이전/다음 페이지네이션 버튼을 통해 과거 데이터를 탐색할 수 있으며 탭 전환 시 1페이지로 자동 리셋됩니다.

**Blocked by:** 01 — 모바일 성과 요약 카드 기간별(연간/월간/일간) 탭 전환 및 데이터 바인딩

**Status:** ready-for-agent

- [ ] 월별 및 일별 데이터 항목이 5개를 초과하는 경우 5개씩 슬라이싱되어 표시되어야 한다.
- [ ] 항목 수가 5개를 초과할 때 하단에 `[< 이전] currentPage / totalPages [다음 >]` 페이지네이션 컨트롤이 표시되어야 한다.
- [ ] '다음' 버튼 클릭 시 다음 5개 항목으로 이동하고, '이전' 버튼 클릭 시 이전 5개 항목으로 이동해야 한다.
- [ ] 첫 페이지에서는 '이전' 버튼이 비활성화되고, 마지막 페이지에서는 '다음' 버튼이 비활성화되어야 한다.
- [ ] 탭(연도별/월별/일별)을 전환할 때 현재 페이지가 항상 1페이지로 자동 초기화되어야 한다.
- [ ] 연도별 데이터는 데이터 수가 5개 이하일 경우 페이지네이션 컨트롤이 노출되지 않아야 한다.
