# 01 — 모바일 성과 요약 카드 기간별(연간/월간/일간) 탭 전환 및 데이터 바인딩

**What to build:** 사용자가 모바일 대시보드의 성과 요약 카드에서 [연도별], [월별], [일별] 세그먼트 탭을 터치하여 기간 단위별 투자 성과(자산평가액, 추가 납입액, 수익률, 수익금)를 전환하고 확인할 수 있습니다.

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 성과 요약 카드 헤더 영역에 [연도별 | 월별 | 일별] 세그먼트 탭 버튼 그룹이 렌더링되고, 기본값으로 '연도별'이 활성화되어 있어야 한다.
- [x] '연도별', '월별', '일별' 탭을 탭(클릭)하면 각각 `yearly`, `monthly`, `daily` 데이터가 즉시 전환되어 표시되어야 한다.
- [x] 연도별은 `YYYY`, 월별은 `YY.MM`, 일별은 `MM.DD` 형태로 배지 날짜가 간결하게 포맷팅되어야 한다.
- [x] 각 항목에 자산평가액, 추가액, 수익률 배지, 수익금이 올바르게 표시되고 수익/손실에 따른 색상 및 아이콘이 적용되어야 한다.
- [x] 마스킹 모드 활성화 시 자산평가액, 추가액, 수익금액이 정상적으로 `***` 마스킹되어야 한다.
- [x] 해당 기간의 데이터가 없을 경우 "해당 기간 성과 데이터가 없습니다." 안내가 표시되어야 한다.
