# 04 — 모바일 웹 지수분석 실기기 뷰포트 E2E 검증 및 스크린샷 점검

**What to build:** 실제 개발 서버(`uv run scripts/dev.py`) 환경에서 내장 브라우저 및 모바일 뷰포트(390×844)로 접속하여, 4대 지수 전환, 3개 차트 서브탭 전환, VIX 기준선 가독성, 터치 툴팁 통합 수치 노출 및 터치 해제 시 즉시 소멸을 시나리오별로 실기 검증하고 스크린샷 기록을 남기는 작업.

**Blocked by:** 01 — 1화면 1차트 서브탭 스위처 및 대형 단독 뷰(260px) 도입, 02 — VIX 기준선(주의 20, 경고 30) 분리 및 가독성 개선, 03 — 지수·MDD·VIX 통합 초슬림 툴팁 및 터치 종료(TouchEnd) 즉시 소멸 구현

**Status:** ready-for-agent

- [ ] 개발 서버(`uv run scripts/dev.py`)를 백그라운드로 실행하고 `http://localhost:5173/m/market`에 접속하여 정상 로드 확인.
- [ ] 모바일 뷰포트(390×844)에서 `[지수 종가]`, `[낙폭 (MDD)]`, `[VIX 변동성]` 탭 전환 시 차트가 부드럽고 큼직하게 렌더링되는지 확인.
- [ ] VIX 변동성 탭에서 주의 20, 경고 30 기준선과 보라색 곡선이 가림 없이 선명하게 보이는지 확인.
- [ ] 차트 터치 시 상단에 지수·MDD·VIX 통합 수치가 뜨고, 터치 해제 시 즉시 소멸하는지 확인.
- [ ] 검증 화면 스크린샷을 `screenshots/` 디렉토리에 저장하고 개발 서버 프로세스를 안전하게 종료한다.
