# 01 — 백엔드 VIX 연동 및 기본 차트 동기화 슬라이스

**What to build:** 데스크탑 웹 지수분석 화면에서 특정 지수(S&P 500, 나스닥, 코스피, 코스닥)를 조회할 때, MDD 차트 하단에 S&P 500 기준 VIX 일별 시계열 차트가 함께 렌더링되고 마우스 호버 커서(syncId)가 지수 종가·MDD 차트와 동일한 날짜 축으로 동기화되어 동작하는 엔드투엔드 기본 파이프라인.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 마켓 데이터 프로바이더에서 `^VIX` 심볼을 인식하여 야후 파이낸스 어댑터를 통해 시세를 수집 및 로컬 캐싱한다.
- [ ] 지수 분석 historical API 응답에 선택한 지수의 날짜와 1:1로 매핑된 `vix` 수치 배열이 포함된다.
- [ ] 한국 지수(KOSPI/KOSDAQ) 조회 시 미국 휴장일로 인한 결측치는 직전 유효 종가(Forward-fill)로 보정되어 결측 없이 반환된다.
- [ ] 3년 초과 기간 조회 시 지수와 동일한 주간(Weekly) 다운샘플링이 VIX에도 적용된다.
- [ ] 지수분석 페이지의 MDD 차트 하단에 VIX 라인 차트가 렌더링된다.
- [ ] 마우스 호버 시 종가 차트, MDD 차트, VIX 차트 간의 커서 툴팁이 동일한 날짜 포인트로 동기화된다.
- [ ] 백엔드 단위 테스트 및 프론트엔드 컴포넌트 렌더링 테스트가 통과한다.
