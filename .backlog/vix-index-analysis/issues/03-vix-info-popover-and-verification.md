# 03 — VIX 안내 툴팁 팝오버 및 E2E 통합 검증

**What to build:** VIX 차트 타이틀 옆의 안내(Info) 아이콘을 통해 VIX의 정의와 4단계 기준선의 통계적 의미(분위수 및 투자 시사점)를 담은 설명 팝오버를 제공하고, 4대 지수 및 다양한 기간에 대한 전체 화면 동작을 브라우저 E2E로 검증하여 완성도를 확보하는 작업.

**Blocked by:** 02 — VIX 4단계 기준선 및 상태 배지 UI 구현

**Status:** resolved

- [x] VIX 차트 타이틀 옆에 Info 안내 아이콘 버튼이 배치된다.
- [x] Info 아이콘 마우스 호버 또는 클릭 시 VIX 개념(CBOE S&P 500 변동성 지수) 및 4단계 기준선(안정/주의/경고/위기) 안내 팝오버가 표시된다.
- [x] 팝오버 외부 클릭 또는 마우스 아웃 시 자연스럽게 닫힌다.
- [x] 브라우저 환경에서 4대 지수(S&P 500, 나스닥, 코스피, 코스닥) 전환 시 VIX 차트가 문제없이 동작함을 확인한다.
- [x] 1년, 3년, 5년, 10년, 전체 등 다양한 기간 필터 전환 시 VIX 차트 동기화가 유지됨을 확인한다.
- [x] 프론트엔드 및 백엔드 전체 테스트 스위트가 깨짐 없이 통과한다.
- [x] E2E 검증 스크린샷이 저장된다.
