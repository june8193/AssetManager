# 02 — 데스크톱 자산 추이 차트(`AssetChart`) '수익 지수(Index)' 탭 전환 및 전용 시각화 UI 구현

**Spec:** [spec.md](../spec.md)

**What to build:** 데스크톱 메인 대시보드(`DashboardPage.jsx`)의 `AssetChart.jsx` 컴포넌트에 `[총자산 규모 (원)]`(기본 활성) / `[수익 지수 (Index)]` 탭 전환 UI를 구현하고, 수익 지수 탭 선택 시 계좌 필터 숨김, 헤더 최신 지수 배지, `1,000 pt` 기준 점선(`ReferenceLine`), 3종 지표 상세 툴팁, 프라이버시 마스킹(`***`) 예외 처리(`pt` 및 `%` 상시 노출)를 완성합니다.

**Blocked by:** `01-portfolio-index-and-live-chart-data`

**Status:** ready-for-agent

- [ ] `AssetChart.jsx` 우측 상단에 `[총자산 규모 (원)]` 탭과 `[수익 지수 (Index)]` 탭 전환 버튼이 렌더링되며, 초기 기본 활성 탭은 `[총자산 규모 (원)]`이다.
- [ ] `[총자산 규모 (원)]` 탭에서는 기존과 동일하게 계좌 선택 드롭다운(`총 자산 합계` 및 개별 계좌)이 표시되고, 차트 맨 끝점까지 실시간 자산 규모 추이가 렌더링된다.
- [ ] `[수익 지수 (Index)]` 탭을 클릭하면 계좌 선택 드롭다운이 숨겨지고, 차트 헤더에 최신 수익 지수 및 기준일 대비 누적 등락률 배지(예: `1,284.50 pt (+28.45%)`)가 표시된다.
- [ ] `[수익 지수 (Index)]` 탭 차트에는 `1,000 pt` 기준 점선(`ReferenceLine`)이 표시되고, 마우스 오버 툴팁에 `내 자산 지수 (pt)`, `직전 대비 등락률 (%)`, `기준일(1,000pt) 대비 누적 등락률 (%)` 3가지 정보가 포맷팅되어 표시된다.
- [ ] 프라이버시 마스킹(`MaskingContext`)을 활성화했을 때 `[총자산 규모 (원)]` 탭의 금액은 `***`로 가려지지만, `[수익 지수 (Index)]` 탭의 Y축, 헤더 배지, 툴팁의 지수(`pt`)와 등락률(`%`)은 마스킹되지 않고 그대로 노출된다.
- [ ] `src/frontend/src/components/Dashboard/AssetChart.test.jsx`에서 탭 전환, 계좌 필터 표시/숨김, 최신 지수 배지 렌더링, 마스킹 예외 동작이 테스트로 검증된다.
