# 01 — 모바일 비중 점검 상태 배지 판별 기준 단일화 및 단위 테스트

**What to build:**
모바일 비중 점검 화면에서 특정 서브카테고리(예: 미국 장기채)나 개별 종목이 상위 카테고리와 과부족 방향이 다를 때 '매수 필요'와 '매도 필요' 뱃지가 동시에 노출되던 문제를 해결합니다. 상태 배지 판별 기준을 비중 편차와 리밸런싱 금액의 OR 조합에서 '리밸런싱 필요 금액' 단일 기준으로 일원화하고, 상호 배타적인 단일 배지만 렌더링되도록 구현합니다. 또한 계층 간 불일치 엣지 케이스 및 배지 상호 배타성 단언을 포함한 단위 테스트를 작성하여 안정성을 검증합니다.

**Blocked by:** None — 즉시 시작 가능

**Status:** claimed

- [x] 계층형 데이터에서 상위 카테고리 대비 비중 편차(%p)와 전체 포트폴리오 기준 리밸런싱 필요 금액(원)의 방향이 반대인 엣지 케이스 단위 테스트 작성 (Red)
- [x] '매수 필요' 배지 노출 시 화면에 '매도 필요' 텍스트가 절대 노출되지 않도록 상호 배타성(Negative Assertion) 검증 단언 추가
- [x] 모바일 비중 카드의 상태 배지 판별 로직을 실제 리밸런싱 필요 금액 단일 기준으로 변경 (Green)
  - 필요 금액이 +1,000원 초과이면 '매수 필요'
  - 필요 금액이 -1,000원 미만이면 '매도 필요'
  - 절댓값 1,000원 이내이면 '적정'
- [x] 상태 배지 UI 렌더링 구조를 상호 배타적 단일 분기로 개선하여 최대 1개의 배지만 표시되도록 보장
- [x] 진행률 게이지 바(Progress Bar) 색상이 단일화된 상태 판별 결과와 일치하도록 연동
- [x] 전체 프론트엔드 단위 테스트 스위트 회귀 통과 확인
