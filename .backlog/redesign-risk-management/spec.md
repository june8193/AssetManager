# Spec: 리스크 관리 메뉴 전면 재설계 — 포트폴리오 내재 변동성 진단 및 매매 시뮬레이터

Status: ready-for-agent

## Problem Statement (문제 정의)

기존 리스크 관리 메뉴와 성과 산출 엔진에는 다음 두 가지 근본적인 문제가 존재합니다.

1. **수식 및 데이터 파이프라인 왜곡**:
   - 시세 캐시에 저장된 휴장일 센티널(`close_price <= 0`)을 걸러내지 않아 일별 수익률이 `-100%`로 오염되는 버그가 발생합니다.
   - 과거 월간 스냅샷과 일간 스냅샷이 혼재된 계좌 잔고 시계열을 단순 기하 등분 보간하여 변동성을 계산하므로 실제 일별 시장 변동성이 축소·왜곡됩니다.
   - 시세 캐시에 남아 있는 과거 조회·관심 종목 등 비보유 티커까지 모두 보유 종목으로 오인하여 비교 목록에 노출하며, 나스닥 벤치마크 티커(`^NDX` vs `^IXIC`)가 다른 메뉴와 불일치합니다.
2. **사용자 의사결정 단절 및 난해한 지표**:
   - 개인 장기 투자자가 직관적으로 매매 판단에 활용하기 어려운 학술적 샤프·소티노 지수 및 무위험 수익률($R_f$) 설정 위주로 UI가 구성되어 있습니다.
   - 투자자가 실제로 원하는 **"3대 벤치마크(S&P 500, NASDAQ, KOSPI) 대비 현재 내 포트폴리오의 흔들림 수준 파악"**과 **"변동성을 높이거나 낮추고 싶을 때 어느 종목을 얼마나 매매해야 하는지 컨트롤"**할 수 있는 수단이 전혀 없습니다.

## Solution (해결 방안)

구버전 샤프·소티노 지수, 무위험 수익률 설정, 공식 안내 모달을 전면 폐기하고, **현재 보유 종목·현금 비중 기반의 `포트폴리오 내재 변동성` 진단 및 실시간 What-if 매매 시뮬레이터**로 처음부터 다시 설계·구축합니다.

1. **도메인 용어 명확화**:
   - 대시보드의 과거 스냅샷 누적 성적표인 `수익 지수 (Index)`(`1,000 pt` 기준)와 혼동되지 않도록 포트폴리오에 '지수(Index)' 명칭을 사용하지 않고 **`포트폴리오 내재 변동성` (현재 보유 비중 기준)**으로 명명합니다. '지수'라는 용어는 시장 벤치마크(`S&P 500`, `NASDAQ`, `KOSPI`)에만 사용합니다.
2. **공분산 행렬 기반 내재 변동성 및 오일러 위험 기여도 산출**:
   - 별도 DB 테이블이나 컬럼을 추가하지 않고, 원장 기준 현재 보유 종목·예수금 비중과 순수 현지 통화 유효 종가(`close_price > 0`) 일별 등락률로부터 종목 간 공분산 행렬($\Sigma$)을 실시간 계산합니다.
   - 포트폴리오 연율화 내재 변동성($\sigma_p = \sqrt{w^T \Sigma w}$), 평소 하루 평균 출렁임($\pm\%$ 및 $\pm$원화 체감 폭), S&P 500 대비 상대 배수, 종목별 오일러 위험 기여도($CC_i$ 및 점유율 $\%$)를 산출합니다.
3. **데스크톱 3단 인터랙티브 UI (확정 프로토타입 기준)**:
   - **상단 진단 섹션**: 벤치마크 대비 내 변동성 위치 스펙트럼 게이지(`0%` 현금 ~ `S&P 500` ~ `NASDAQ` ~ `KOSPI`), 3열 요약 KPI 카드, `액셀 Top 3` 및 `완충 자산` 빠른 가이드 배너.
   - **중단 시각화 차트 섹션 (접기/펼치기 지원)**: `[종목별 자체 변동성 vs 기여도]` 비교 바 차트 탭과 `[벤치마크 대비 낙폭(MDD) 방어력]` 비교 곡선 차트 탭.
   - **하단 실시간 매매 시뮬레이터 섹션**: 종목 금액 조절 시 차액이 현금 잔고에 자동 가감되는 실제 계좌 매매 방식의 What-if 시뮬레이터(슬라이더, 직접 입력, 빠른 금액 버튼, 전량매도, 여유자금 추가/인출, 미보유/관심종목 편입 테스트, 정렬, 초기화).
4. **모바일 및 MCP 정합성 정리**:
   - 리스크 관리 화면은 데스크톱 전용으로 유지하고, 모바일 벤치마크 비교 화면의 구버전 포트폴리오 성과 API 호출을 제거합니다.
   - 자산·비중 조회 MCP 도구(`get_portfolio_status`, `get_asset_ratios`)의 구버전 샤프·소티노 필드를 신규 내재 변동성 요약 지표로 교체합니다.

## User Stories (사용자 스토리)

1. As an 투자자, I want 3대 벤치마크(`S&P 500`, `NASDAQ`, `KOSPI`)와 현재 내 포트폴리오의 연율화 내재 변동성을 하나의 수평 스펙트럼 게이지와 배수(`S&P 500의 X.XX배`)로 비교하기를, so that 지금 내 포트폴리오 구성이 시장 대비 어느 정도 체급의 위험을 지고 있는지 직관적으로 파악할 수 있다.
2. As an 투자자, I want 연율화 변동성뿐 아니라 평소 하루 평균 출렁임(`±%` 및 `약 ±OO만원`)을 확인하고 금액 마스킹 설정과 연동되기를, so that 하루 장중 계좌 변동 폭을 실감 나게 인지하면서도 화면 공유 시 자산을 보호할 수 있다.
3. As an 투자자, I want 변동성 측정 기준 기간을 `1개월(단기)`, `3개월`, `1년(표준)`으로 전환하기를, so that 종목들의 고유 변동성 체급(1년)과 최근 단기 장세의 거칠기(1~3개월)를 구분해 확인할 수 있다.
4. As an 투자자, I want 현재 보유 종목별 자체 변동성과 포트폴리오 흔들림 기여도(점유율 `%`), 그리고 `액셀 Top 3`·`완충 자산` 가이드를 한눈에 보기를, so that 변동성을 줄이거나 늘릴 때 어떤 종목을 우선 매매해야 하는지 즉시 알 수 있다.
5. As an 투자자, I want `[종목별 자체 변동성 vs 기여도]` 바 차트와 `[벤치마크 대비 낙폭(MDD) 방어력]` 곡선 차트를 탭으로 전환하거나 접어 두기를, so that 필요할 때만 시각적 분석을 참고하고 컴팩트한 작업 공간도 선택할 수 있다.
6. As an 투자자, I want 종목별 슬라이더, 금액 직접 입력, 빠른 매매 버튼(`-500`, `-100`, `+100`, `+500`, `전량매도`)으로 보유 금액을 조절할 때 매도·매수 차액이 현금 잔고에서 자동으로 가감되고 현금이 마이너스가 되면 부족 경고가 표시되기를, so that 실제 계좌 자금 흐름대로 변동성 조절을 시뮬레이션할 수 있다.
7. As an 투자자, I want 신규 여유자금 추가/인출 금액을 반영하고 언제든 `시뮬레이션 초기화` 버튼으로 원래 상태로 복귀하기를, so that 추가 납입 또는 인출 시나리오까지 자유롭게 테스트할 수 있다.
8. As an 투자자, I want `+ 미보유/관심종목 편입 테스트` 기능을 통해 관심종목이나 국내·미국 검색 종목을 시뮬레이션에 추가해 편입 효과를 확인하기를, so that 아직 사지 않은 신규 종목이나 ETF를 매수했을 때 전체 변동성이 어떻게 변하는지 사전에 검증할 수 있다.
9. As an AI 에이전트 및 자산 관리자, I want `get_portfolio_status` 및 `get_asset_ratios` MCP 도구가 구버전 샤프·소티노 대신 검증된 `포트폴리오 내재 변동성` 요약 지표를 반환하기를, so that 투자 상담 및 복기 시 정확한 리스크 수치를 인용할 수 있다.

## Implementation Decisions (구현 결정사항)

### 1. 도메인 불변식 및 수학 연산 모델
- **DB 무변경 원칙**: 별도 변동성 저장 테이블이나 스키마 마이그레이션을 추가하지 않으며, 원장 보유 수량, 예수금 잔고, 기준 환율, 역사적 시세 캐시로부터 요청 시 실시간 계산합니다.
- **기준 기간**: `1M`(30일), `3M`(90일), `1Y`(365일, 기본값).
- **대상 자산 구성**:
  - 현금 버킷(`CASH`): 원화 예수금과 기준 환율로 원화 환산된 달러 예수금의 합계. 현금의 일별 수익률, 연율화 변동성, 타 자산과의 공분산은 모두 `0.0`으로 고정합니다.
  - 보유 비현금 자산: 원장 엔진 기준 현재 보유 수량(`quantity > 0`)이 존재하는 종목만 포함합니다.
  - 시뮬레이션 추가 종목(`extra_tickers`): 현재 보유 평가액은 `0원`으로 포함하며, 공분산 행렬과 일별 수익률 시계열을 함께 내려 클라이언트 시뮬레이션을 지원합니다.
- **시세 동기화 및 순수 주가 등락률 정제**:
  - 마켓 데이터 프로바이더를 통해 선택 기간의 누락 시세를 동기화한 뒤, 반드시 `close_price > 0`인 유효 거래일 종가만 사용하여 현지 통화 기준 일별 단순 수익률 $r_{i,t} = (P_{i,t} - P_{i,t-1}) / P_{i,t-1}$을 계산합니다.
  - 미국 자산 및 달러예수금에는 일별 환율 변동성을 합산하지 않습니다(포트폴리오 비중 계산 시에만 최신 기준 환율 적용).
- **공분산 행렬($\Sigma$) 및 PSD 보정**:
  - 개별 자산 연율화 변동성: 표본 표준편차(`ddof=1`) $\times \sqrt{252} \times 100$.
  - 자산 쌍 $(i, j)$의 연율화 공분산: 공통 유효 거래일 교집합(최소 2거래일 이상)에 대한 표본 공분산 $\times 252 \times 100^2$ (교집합이 부족한 경우 `0.0`).
  - 비동기 영업일 결측으로 인한 비양의 준정부호(non-PSD) 왜곡을 방지하기 위해 공분산 행렬을 대칭화한 뒤 고유값 분해를 거쳐 음수 고유값을 `0.0`으로 클리핑(PSD 보정)하여, 임의의 가중치 벡터 $w$에 대해 항상 $w^T \Sigma w \ge 0$을 보장합니다.
- **내재 변동성 및 오일러 위험 기여도**:
  - 포트폴리오 연율화 변동성: $\sigma_p = \sqrt{\max(0, w^T \Sigma w)}$
  - 평소 하루 평균 출렁임: $\sigma_{\text{daily}} = \sigma_p / \sqrt{252}$, 원화 체감 폭 $= \text{TotalKRW} \times (\sigma_{\text{daily}} / 100)$
  - 종목별 기여도(Component Volatility): $CC_i = w_i \frac{(\Sigma w)_i}{\sigma_p}$ ($\sigma_p > 0$), 기여 점유율 $\text{Share}_i = \frac{CC_i}{\sigma_p} \times 100\%$ ($\sum_i \text{Share}_i = 100\%$).
- **MDD 방어력 비교 시계열**:
  - 3대 벤치마크(`^GSPC`, `^IXIC`, `^KS11`)의 유효 영업일 합집합 그리드(`dates`) 상에서 각 벤치마크의 누적 낙폭($\text{DD}_t \le 0\%$) 시계열과 각 자산의 정렬된 일별 수익률 배열(해당 시장 휴장일은 `0.0`)을 생성합니다.
  - 합성 누적 지수 $I_0 = 100, \; I_t = I_{t-1}(1 + \sum_i w_i r_{i,t})$로부터 현재 비중과 시뮬레이션 비중 모두의 $\text{DD}_t(\%)$ 곡선을 산출합니다.

### 3. 클라이언트 실시간 시뮬레이터 상태 전이 규칙 (출처: 확정 프로토타입 `risk_management_prototype.html`)
- 초기 로드 또는 기간/추가 종목 변경 시에만 백엔드 API를 호출하며, 슬라이더·금액 입력·빠른 버튼·여유자금 조작 시에는 서버 재요청 없이 클라이언트 메모리에서 공분산 행렬과 `asset_daily_returns`를 이용해 `0ms` 지연으로 재계산합니다.
- **현금 자동 정산 불변식**:
  ```javascript
  simCash = baseCash + extraCashKrw - sum(simVal[i] - baseVal[i] for non-cash i)
  effectiveCash = Math.max(0, simCash)
  isCashShortage = simCash < 0
  ```
  - 비현금 종목을 매수(증액)하면 `simCash`가 감소하고, 매도(감액)하면 `simCash`가 증가합니다.
  - `simCash < 0`일 경우 비중 계산에는 `effectiveCash = 0`을 사용하되, UI에 부족 금액(`|simCash|`) 경고 배지를 표시합니다.
- 신규 미보유 종목 추가 시에는 기존 관심종목 목록 조회 및 국내/미국 종목 검색 API를 활용하며, 선택된 티커를 `extra_tickers` 쿼리 파라미터로 백엔드에 요청해 시세·공분산 데이터를 병합합니다.

### 4. 레거시 제거 및 외부 소비자 전환
- 구버전 성과 분석 라우터(`/api/v1/performance/*`: 무위험 수익률 설정, 포트폴리오/개별자산/일괄 샤프·소티노 계산), 해당 서비스 및 테스트, 구버전 리스크 관리 페이지와 공식 안내 모달을 완전히 제거합니다.
- 데스크톱 사이드바 경로(`/performance`, 메뉴명 `리스크 관리`) 및 페이지 타이틀 매핑은 기존 URL 호환성을 위해 유지하되 내부 화면을 전면 교체합니다.
- 모바일 환경에는 리스크 관리 메뉴를 추가하지 않으며, 모바일 벤치마크 비교 컴포넌트에서 구버전 포트폴리오 성과 API 병렬 호출을 제거하고 기존 벤치마크 차트 시계열 기반 MDD 산출 로직만 사용하도록 정리합니다.
- MCP 도구(`get_portfolio_status`, `get_asset_ratios`)는 구버전 `sharpe_ratio`, `sortino_ratio`, `mdd`, `max_mdd` 필드를 제거하고 `GET /api/v1/risk/volatility?period=1Y`에서 가져온 `portfolio_volatility`, `daily_volatility_pct`, `sp500_volatility_ratio` 요약 지표를 병합합니다.

## Testing Decisions (테스트 결정사항)

- **검증 원칙**: 내부 구현 세부사항이 아닌 공개 인터페이스(HTTP API, 렌더링된 UI 인터랙션, MCP 도구 반환값)와 수학적 불변식을 검증합니다.
- **사전 합의된 테스트 심 (Pre-agreed Seams)**:
  1. **백엔드 리스크 변동성 HTTP API 심 (`FastAPI TestClient` + 인메모리 SQLite + Fake 마켓 어댑터)**:
     - **Catches**: 휴장일 `close_price <= 0` 오염, 현지 통화 수익률·PSD 공분산 행렬·내재 변동성($\sqrt{w^T \Sigma w}$)·오일러 기여도 합산 불변식($\sum \text{Share}_i = 100\%$)·기간 필터(`1M`/`3M`/`1Y`)·`extra_tickers` 확장 및 구버전 `/api/v1/performance/*` 제거 회귀를 잡아낸다.
     - **Misses**: 실제 외부 증권사/Yahoo Finance 라이브 네트워크 응답과 브라우저 DOM 렌더링은 놓친다.
  2. **데스크톱 리스크 관리 페이지 통합 심 (`Vitest` + `React Testing Library` + `MaskingProvider`)**:
     - **Catches**: 기간 전환, 스펙트럼 게이지 마커 갱신, 2종 차트 탭 전환 및 접기, 슬라이더·빠른 금액 버튼·전량매도·여유자금 입력에 따른 현금 자동 정산과 현금 부족 경고, 미보유 종목 추가, 금액 마스킹(`***`) 동작의 UI 상태 전이 오류를 잡아낸다.
     - **Misses**: 실제 백엔드 프로세스와의 라이브 네트워크 연결 및 실제 뷰포트 픽셀 스타일링은 놓친다.
  3. **MCP 자산·비중 도구 공개 인터페이스 심 (`pytest` 비동기 MCP 함수 호출 + API 클라이언트 스텁)**:
     - **Catches**: `get_portfolio_status`·`get_asset_ratios` 응답에서 구버전 샤프·소티노 필드 잔존 여부, 신규 변동성 요약 지표 병합 정확성 및 백엔드 오류 시 안전한 폴백 처리를 잡아낸다.
     - **Misses**: IDE와 MCP 서버 간 실제 프로세스 트랜스포트 연결은 놓친다.
- **참고 테스트 패턴**: 인메모리 DB 픽스처 기반 백엔드 라우터 통합 테스트(`uv run pytest` 순차 실행 필수, 병렬 실행 금지) 및 `MaskingProvider` 래핑 기반 페이지 통합 테스트(`Vitest`).

## Out of Scope (범위 제외 사항)

- 모바일 환경 신규 리스크 관리 메뉴/서브탭 추가 (데스크톱 전용 유지).
- 일별 USD/KRW 환율 변동성을 미국 주식·달러예수금 변동성에 합산하는 통화 변동성 모델.
- 과거 계좌 스냅샷 잔고 시계열 기반 실현 변동성 또는 DB 내 변동성 계산 결과 영구 저장 테이블.
- 샤프 지수, 소티노 지수, 무위험 수익률($R_f$) 설정 기능.
