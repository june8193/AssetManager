# 03 — 기준일 안내 캡션 및 3단 설명 팝오버 툴팁 구현

**What to build:**
최상단으로 이동한 초과수익률 표 헤더 영역에 최신 스냅샷 기준일과 수익률 비교 기준일을 캡션으로 표시하고, 도움말 아이콘을 클릭했을 때 두 기준일의 정의와 시장 휴장일 보정에 따른 정규화 필요성을 친절하게 설명해 주는 3단 팝오버(Popover) 카드를 제공합니다.

**Blocked by:** 02 — 상단 요약 카드 제거 및 초과수익률 분석 표 최상단 이동

**Status:** ready-for-agent

- [ ] 초과수익률 분석 표 상단 헤더 영역에 `최신 스냅샷 기준일: YYYY-MM-DD` 및 `수익률 비교 기준일: YYYY-MM-DD` 캡션 텍스트가 표시된다.
- [ ] 캡션 옆에 도움말(`HelpCircle` 또는 `Info`) 아이콘 버튼이 표시된다.
- [ ] 도움말 아이콘 클릭 시 토글되는 안내 팝오버 카드가 렌더링된다.
- [ ] 팝오버 카드 내부에 3단 설명(1. 최신 스냅샷 기준일 정의, 2. 수익률 비교 기준일 정의, 3. 두 기준일이 다르고 필요한 이유/시장 휴장일 안내)이 깔끔하게 표시된다.
- [ ] 팝오버 카드 내부의 닫기 버튼을 클릭하거나, 팝오버 카드 외부 영역을 클릭하면 팝오버가 정상적으로 닫힌다.
- [ ] 캡션 렌더링 및 팝오버 열림/닫힘 상호작용에 대한 단위 테스트(`BenchmarkPage.test.jsx`)가 작성되고 통과한다.
- [ ] 전체 기능 구현 후 E2E 브라우저 검증이 완료된다.
