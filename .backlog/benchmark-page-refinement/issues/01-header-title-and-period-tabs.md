# 01 — 헤더 타이틀 일원화 및 기간 선택 탭 바 구현

**What to build:**
사용자가 벤치마크 페이지에 접속했을 때 사이드바 메뉴명('벤치마크 비교')과 일치하는 '벤치마크 비교' 타이틀 및 명확화된 설명 문구를 확인하고, 기존 드롭다운 대신 제공되는 기간 탭 바(`올해 누적 (YTD)`, `1개월`, `3개월`, `1년`)를 클릭하여 즉시 조회 기간을 변경할 수 있는 일관된 헤더 인터페이스를 구축합니다.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 페이지 상단 제목이 '시장분석 대시보드'에서 '벤치마크 비교'로 표시된다.
- [ ] 부제목이 '주요 시장 지수 대비 포트폴리오 성과 및 초과수익률(Alpha)을 비교 분석합니다.'로 표시된다.
- [ ] 헤더 우측에 기존 드롭다운(`<select>`) 대신 `올해 누적 (YTD)`, `1개월`, `3개월`, `1년` 탭 버튼 그룹이 렌더링된다.
- [ ] 각 기간 탭 클릭 시 활성화 상태 스타일이 적용되며 선택된 기간에 맞게 `period` 상태가 변경된다.
- [ ] 기간 탭 우측에 기존 새로고침 버튼이 자연스럽게 유지되어 클릭 시 데이터를 갱신한다.
- [ ] 변경된 헤더 타이틀 및 탭 전환 동작에 대한 컴포넌트 단위 테스트(`BenchmarkPage.test.jsx`)가 통과한다.
